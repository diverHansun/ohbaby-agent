# 03 本模块验收重点

- **真实身份与当前值（T02、T03、T06、T07）**：多次模型步骤、正文与思考、断线时的未完成输出用源头 ID 对齐；不能只向 reducer 注入预先整理好的正确事件。
- **结束与存储隔离（T26–T29）**：重复结束幂等；挂起展示保存 Promise 时，下一步正文和工具仍推进；DB 写完但结果未提交的历史仍显示 pending；已结束失败缓存超限只影响展示内容。
- **模型上下文（T27）**：保存展示文本前后，后续模型输入、摘要、原生 model-state 及合法同轮回传保持原语义。
