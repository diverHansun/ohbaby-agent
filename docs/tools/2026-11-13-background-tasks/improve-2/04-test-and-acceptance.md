# 自动转换测试与验收

状态：未运行。复用 improve-1 的真实 SQLite、进程组清理和通知测试；长阈值用可注入时钟，真实进程用短阈值验证。

| 编号 | 场景 | 判定 |
| --- | --- | --- |
| A01 | 默认配置，无 timeout，运行超过等待阈值 | 120 秒前为前台、不占后台额；到点转换后继续运行，无隐式 120 秒硬终止。 |
| A02 | 全局关闭、单次关闭及冲突参数 | 纯前台默认硬超时 120 秒；模型不能绕过全局关闭；非法组合在 spawn 前拒绝。 |
| A03 | 显式后台，全局自动转换关闭 | 仍立即后台；未传 timeout 不限时，传值最大 24h。 |
| A04 | 调整 wait_ms；各路径 timeout 上下界 | 范围、单位、整数验证正确；纯前台最多 10min，自动/显式后台最多 24h；等待不是寿命。 |
| A05 | 显式 timeout 早于、等于、晚于等待阈值 | 前两种先 timed_out，后一种转换后仍在原截止时刻终止，不重置计时。 |
| A06 | 自然退出与转换同一时刻发生 | 已确定终态不转换、不占额、不重复通知；返回同一任务事实。 |
| A07 | 两个前台命令竞争最后一个后台名额 | 只有一个转换；另一命令 cancelled + capacity-limit；不杀旧任务、不重跑、不超额。 |
| A08 | 当前轮 Stop 与转换提交前后竞争 | 覆盖写锁等待、COMMIT到Promise resolve间与完成后；提交前按前台取消，提交后主代理后台保留；各路径无遗留 abort listener 或双重释放。 |
| A09 | 子代理正常交付、失败、停止与转换竞争 | 所属任务都受本次执行回收约束；新准入封闭，无孤儿，无跨 owner 影响。 |
| A10 | 转换写库失败、写锁排队期间Stop/超时/自然退出、计时回调晚到、终态晚到 | 不返回虚假转换成功；持久化失败报告 internal-error，有已知输出与清理事实，责任不提前释放，旧计时回调不覆盖终态；获锁后重新检查，不能把等待锁前的running判断用于提交。 |
| A11 | 大量输出发生在转换前，随后结束/重启 | 尾部真实，记录和日志同一个 jobId；不把前台头部当尾部，不丢弃已知截断信息。 |
| A12 | 转换后继续调用其他工具，后台单停或超时 | 普通工具槽释放，环境引用保留到回收；停止未确认时资源保护仍有效。 |
| A13 | 转换回执与任务结束同时发生，主代理繁忙/空闲 | 成功回执不等于完成结果；已后台的结束事件按 improve-1 可靠送达，容量拒绝不新开后台唤醒。 |
| A14 | task list/output/stop、UI 后端查询、回滚检查 | 读取同一 mode/ID/deadline，按实际状态管理；回滚仍定位原始启动轮次。 |
| A15 | 无完整管理工具的角色请求显式/自动后台 | 启动前拒绝并说明能力缺失，不生成无法管理的任务；能力限定纯前台的角色在未显式请求后台时可执行普通短命令，按纯前台硬超时和既有权限处理；显式后台策略仍拒绝。 |
| A16 | 合并后的旧代码清理 | 无第二套计时器驱动进程寿命，无死的初始模式取消分支；迁移前后调用责任与进程责任测试完整。 |

验收以受影响单元、调度集成、真实进程和 SQLite 测试为准，最终完成项目要求的 preflight。只做后端，不写前端通过结论；不在规划期生成 05。所有测试需记录真实结果，不能用文档案例代替执行。
