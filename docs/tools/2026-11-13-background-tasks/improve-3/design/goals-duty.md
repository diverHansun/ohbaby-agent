# 目标与职责

状态：待实施设计。产品决定见 [00](../00-discussion.md)。

## Design Goals

1. 模型用 `bash` 启动、用 `task` 管理，主代理和子代理使用同一套清楚的操作。
2. 合并工具名字时保留真实状态、有界等待、单停和归属隔离。
3. 新入口可迁移，旧历史可读取，不制造第二个运行时或重复持久状态。

## Duties

- 声明 list/output/stop schema，验证参数、动作和可信调用身份。
- 把三个动作映射到既有 ShellJob 服务；按动作设置权限和调度语义。
- 返回简明正文与有界结构化快照，供模型、持久消息和上下文投影消费。
- 更新工具注册、内置角色、提示词、历史读取和回滚兼容。

## Non-Duties

- 不启动进程，不重新实现 Bash 权限分析或自动转换。
- 不管理 agent 执行，不提供跨 owner 管理能力；用户会话树接口仍单独授权。
- 不改变硬超时、额度、通知策略、日志上限、子代理结束回收策略。
- 不实现前端面板，不增加交互 stdin、任务转移、重试、暂停或手动转换。
