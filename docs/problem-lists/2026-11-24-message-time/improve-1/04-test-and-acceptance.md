# 4. 测试与验收

## 4.1 测试策略

- **格式化和跨零点**是纯逻辑，写单测：`apps/ohbaby-web/src/ui/conversation/message-time.unit.test.ts`、`apps/ohbaby-web/src/ui/shared/use-day-clock.unit.test.tsx`。
- **时间在操作行里的位置和显隐**是渲染结构，写进现有的 `apps/ohbaby-web/src/ui/conversation/message-copy.unit.test.tsx`，它已经搭好了带操作行的会话。
- **侧边栏**改现有的 `apps/ohbaby-web/src/ui/sidebar/Sidebar.unit.test.tsx`。
- **视觉**用 `.claude/launch.json` 里的 `ohbaby-web-mock` 启动，在浏览器里读计算后的样式并截图。mock 数据的时间都是"几分钟前"，所以浏览器里只能看到"今天"的格式，其他格式靠单测。
- 所有单测的时间输入都用本地时间构造，例如 `new Date(2026, 10, 24, 14, 32).toISOString()`，不写死带 `Z` 的字符串。仓库没有固定 `TZ`，这样在任何时区跑结果都一样。

## 4.3 时钟验收

| 编号 | 场景 | 通过标准 |
|---|---|---|
| D-1 | 假时间设在 2026-11-24 23:59:30，推进到 2026-11-25 00:00:01 之后 | `useDayClock` 返回的 `now` 更新到新的一天 |
| D-2 | 同一天内推进 1 小时 | `now` 不变，组件不重绘 |
| D-3 | 跨天后触发 `visibilitychange`（页面变为可见），且定时器没有触发 | `now` 更新到新的一天 |
| D-4 | 组件卸载 | 定时器和事件监听都被清掉 |

## 4.4 渲染验收

| 编号 | 场景 | 通过标准 |
|---|---|---|
| R-1 | 用户消息的操作行 | 顺序是时间、复制、编辑（能编辑时），时间是 `<time>` 元素，`dateTime` 是原始 ISO 字符串 |
| R-2 | 回答的操作行 | 顺序是复制、Fork、时间；side chat 里是复制、时间 |
| R-3 | 回答带 `completedAt` | 显示 `completedAt` 的时间，不是 `createdAt` |
| R-4 | 回答没有 `completedAt` | 显示 `createdAt` 的时间 |
| R-5 | 时间的 `title` | 是完整格式 `YYYY-MM-DD HH:mm` |
| R-6 | 压缩摘要、正文为空的消息 | 没有操作行，也没有时间 |
| R-7 | 最新一条回答 | 操作行带 `is-persistent`，时间常显 |

## 4.5 浏览器验收

| 编号 | 场景 | 通过标准 |
|---|---|---|
| B-1 | `?mock=typical`，hover 一条旧的用户消息 | 时间出现在复制按钮左边，11.5px，颜色是 `--text-dim` |
| B-2 | 同一会话的最新回答 | 不 hover 也能看到「复制 · Fork · 时间」 |
| B-3 | 时间和按钮的垂直对齐 | 时间文字的中线和按钮图标的中线一致 |
| B-4 | 打开 side chat 和子代理页 | 都显示时间，操作行没有换行或挤压 |
| B-5 | 侧边栏所有会话行 | 行尾没有时间 |
| B-6 | hover 一个标题很长的会话行，再 hover 一个置顶的长标题行 | 标题被截断在「…」（置顶行是 pin 和「…」）左边，没有被按钮盖住 |
| B-7 | 在系统设置里把时区改成另一个时区，刷新页面 | 消息时间跟着系统时区变化 |

B-1 到 B-6 在桌面宽度和 375px 手机宽度下各看一遍。ohbaby 现在没有深色模式，不用测。

## 4.6 对抗性审查要点

- 有没有地方用了 `getUTCHours`、`toISOString().slice(...)` 这类 UTC 取值来显示时间？显示必须走本地取值。
- `useDayClock` 是不是在 `ConversationStream` 顶部无条件调用？放进条件分支会违反 hook 规则。
- `relative-time.ts` 和 `useMinuteClock` 还在吗？归档列表、子代理列表、文件列表、文件预览还在用它们。
- 侧边栏的 `.ohb-session-meta` 还在吗？删掉它会让 hover 按钮盖住标题。
- 置顶行 hover 时，meta 的计算宽度是不是 48px？
