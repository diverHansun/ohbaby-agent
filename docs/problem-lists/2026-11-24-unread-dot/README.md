# 侧边栏未读点

本议题于 2026-11-24 开启：一个会话答完了，但用户当时在看别的会话，侧边栏就在这个会话前面亮一个蓝点，打开后熄灭。后端和 Web 都有小改动；界面只做 Web，不做 TUI。
