# 0. 讨论与已确认要点

> 本文记录 2026-11-23 讨论后确认的结论，被否决的方案不再展开。

## 0.1 用户提出的问题

LLM 输出 Markdown 表格时，应该能好好显示成表格。做法借鉴 `code-cli/` 下的 opencode、deepseek-harness（下文简称 dsh）和 ZCode。

## 0.2 已确认的决定

| 编号 | 决定 |
|---|---|
| C1 | 3 列及以下铺满正文宽度，4 列及以上按内容自然撑开，放不下就横向滚动 |
| C2 | 宽表的单元格最小 100px、最大 320px，超出后换行 |
| C3 | 字号 13px，数字等宽 |
| C4 | 只用细横线，不加外框、底色和斑马纹 |
| C5 | 首列左侧和末列右侧不留内边距，表格文字和正文左边对齐 |
| C6 | 支持 Markdown 的左、中、右对齐语法 |
| C7 | 实现上给 `marked` 加一个表格渲染器，外面包一层滚动容器，再按列数加样式名 |

## 0.3 明确不做

- 不做复制表格、导出 CSV、全屏和排序。LLM 输出的表格主要是拿来读的。
- 不做 TUI。
