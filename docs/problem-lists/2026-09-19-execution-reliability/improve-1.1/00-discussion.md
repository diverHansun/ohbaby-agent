## 延续的边界

- 审批按钮只由当前根会话的审批同步结果控制；聊天历史或其他数据失败不能锁住已恢复的审批。
- Web 多页共享同一 serve；页面关闭、切换、刷新、断网不取消后台任务。默认 TUI 是 in-process，不连接 daemon。
- 子会话不能当主会话使用；只读子代理界面及根会话审批入口延续原规划，本轮不新增子会话发送/审批入口。
- 浏览器验收由 agent 启动真实构建产物并实际操作，使用测试模型；不以固定点击脚本代替。竞态的单元/集成测试仍使用确定性控制。
- 各模块改造说明放新建 improve 子目录，与 problem-lists 双向链接；不直接改原模块设计。
