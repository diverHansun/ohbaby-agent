# 测试与验收标准

本页是未来实施的验收门，**本轮规划未运行或宣称通过这些测试**。遵循 [项目测试规范](../../../../docs-test/README.md) 和 [Web 测试职责](../../../ohbaby-web/test.md)：unit/contract 尽量就近，跨包 integration 放集中目录；真实模型单独 opt-in。浏览器端到端是行为验收层，不以基础 smoke 替代。

## 必须覆盖的风险

| 编号 | 类型与主要对象 | 通过标准 |
| --- | --- | --- |
| T01 | unit：展示排序、身份合并、状态 | Queued→启动中→正式父消息始终一个 ID/气泡；当前轮持续输出不进入下一委派段；终止未启动项不消失、不永久 Queued；同毫秒接受有唯一持久顺序，启动不换排序键 |
| T02 | SQLite integration：host/execution/message | 接受时预留 ID，幂等请求重试不换 ID；前一轮模型读历史看不到排队 prompt；实际开始只写一次正式 user message |
| T03 | contract/integration：scope 和授权 | 同物理 childSession 两个子代理不串内容；同子跨 run 连续；越 root/scope cursor 与订阅、绑定变更期间读取都被拒绝/丢弃 |
| T04 | contract：anchor window | 第一/中间/最新/Queued 委派都能有界查询定位，不扫描全历史；窗口有前后边界；旧缺锚点明确降级，不猜 prompt；跨页 Queued 启动后完整遍历无遗漏/重复 |
| T05 | SDK/server integration：增量恢复 | 文字、思考、工具、终态顺序正确；重复、乱序、缺口、快照竞态和重启 generation 都可恢复，无旧 Queued 复活、历史覆盖新 delta；打开很旧委派时实时尾部有完整 part 基线，缓存有界且不陷入恢复循环 |
| T06 | Web integration | 根不卸载；单浮层切换；浮层/放大同内容；不同 scope 滚动和展开独立；同 child 历史卡片显式锚点覆盖保存位置 |
| T07 | compiled browser E2E | 实际服务与构建 Web 完成任务行→浮层→放大→返回；渐进文字/思考/工具可见；终态自然保留；同时观测根/子内容不串流 |
| T08 | 控制面回归 | child 打开时发送/Enter/Steer/Stop/审批均不可触发；只返回根操作；审批在等待期间到来可被发现；草稿、根滚动、pending 状态保留 |
| T09 | 错误与旧数据 integration | 开启详情失败、断网重连、目标丢失、缺思考、仅有存储结果、迁移前记录均有可解释降级；缓存不冒充实时结果 |
| T10 | 视觉/无障碍验收 | 主列浮层不覆盖输入框，窄屏/矮窗口可阅读；少用点分隔；焦点/键盘/减少动态效果正确；工具样式与根一致 |
| T11 | opt-in 真实 LLM integration/E2E | 实际多次委派同一子代理，忙时接收后续 prompt；核对 UI、ledger、正式消息身份和模型上下文；无需重跑无关百万上下文压测 |
| T12 | TUI/兼容回归 | 验证保留 TUI Ctrl+G 内部详情及原交互；共享 SDK 变更不迫使旧消费者接收新视图，不改变 in-process 模式 |

## 对抗场景

快速点击 A→B→A，同时 A 的旧请求迟到；从老委派定位后切放大；正在向前加载时当前轮继续输出；下一个委派排队后当前轮失败/超时；审批在浮层打开后到达；多个 scope 共用一个物理 session；页面刷新正好跨 Queued→正式消息；根绑定改变时订阅仍有缓存事件。每个场景既断言用户看到的结果，也断言不可发生的串内容、重复写入或越权读取。

## 浏览器与真实模型执行要求

实施时可在代理进程启动本地服务，使用独立测试数据库/端口并在结束后清理。编译产物路径沿用 `pnpm test:e2e:compiled-web` 的现有骨架，扩展真实浏览器行为覆盖；不能把仅 HTTP 接口成功写作视觉验收。

真实请求按 `tests/models-4-tests.md` 使用已配置环境。凭据只交给进程，不打印、不进入截图或报告。优先用可控 LLM fixture 验证队列竞态，再用少量真实请求验证流式链路和真实 tool call 关联；真实请求未触达目标时记为未覆盖，不用概率运行冒充确定性测试。

建议视觉矩阵：常用桌面宽屏、720px 临界宽度、390px 窄屏、低高度窗口、200% 缩放和 reduced-motion。以主列可用尺寸为依据，记录 composer/浮层 bounding box；间隙目标 10px，父气泡和长工具输出不撑破容器。

## 整轮完成条件

阶段 A/B 身份和协议门先通过，再验收 UI。运行相关 unit、contract、integration 后，完成项目 typecheck/lint/build 与受影响回归；最终运行项目完整测试，记录现存失败和跳过，不以测试数替代场景证据。

独立子代理审查重点：模型历史污染、根授权、scope 版本、缺口历史、终态和旧数据。Pi 规划复审不等于实施验收；实施后若沿用用户要求的 Pi 审查，提供实际 diff 和测试证据，针对 UI/CSS 与契约偏差集中审一次。

所有必需场景通过或由用户明确接受限制后，才创建本轮 05；记录基线、实际改动、测试与浏览器证据、真实模型请求范围、未覆盖项。通过验收仍不自动 merge/push。

## 用户验收补修门

- 内部通知在实时、历史、刷新、子浮层/放大页全部隐藏且无空行；同文字的普通消息不被误删，主代理正常进度保留；模型继续收到内部通知。
- 已有统计的历史会话加载、查询后顶栏同步、会话切换不串值；重启后无 runtime 时仍能按原方式查询历史会话占用；统计查询不发真实模型请求，不改变上下文内容或计算算法。
- 缓存原进程内累计与实时展示不重复累计，主/子 scope 隔离；重启不读取历史改写累计；未知、0%、非零正确区分；cache 仅在 /status 展示，Context Usage 不显示 cache。
- 单元/集成、独立子代理审查、Pi 整体/视觉审查、原生浏览器桌面及窄屏操作验收。历史真实模型测试缺口仍单独保留，不用这次局部测试替代。
