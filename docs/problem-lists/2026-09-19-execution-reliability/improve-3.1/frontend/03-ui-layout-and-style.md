# 布局与样式

用户确认的是轻量任务行、上滑浮层、输入框留白、放大阅读和英文文案。以下数值为基于当前 CSS 与 Pi 咨询的**建议默认值**，可在实际浏览器验收中微调，不另起整站视觉规范。

## 主会话入口

移除顶部 Subagents header。委派行沿用当前工具条目的字号、间距和图标尺度，展示简短任务说明与状态；说明单行省略，完整 prompt 在子会话内阅读。状态以字色和留白区分，不拼接一串 `·`，不显示内部执行 ID。普通工具仍用原展开/折叠卡片。

## 浮层

```text
主会话 header
主会话历史（仍可点击露出的任务行）
       ┌ 子任务标题     状态             ⤢   × ┐
       │                                        │
       │    From parent                         │
       │    蓝色父消息                          │
       │    思考 / 正文 / 原样式工具卡           │
       └────────────────────────────────────────┘
                          10px
       ┌ Read-only subagent                    ┐
       │                                        │
       └────────────────────────────────────────┘
```

- 定位于主内容列，左右与主 composer 可用宽度对齐，宽度上限 800px；常规两侧留 24px，≤720px 留 14px。最终以主列宽度计算，不能使用整个窗口宽度覆盖侧栏。
- 高度统一为 `min(680px, 0.64 × availableHeight)`；availableHeight 是状态栏下沿到“输入框上沿 − 10px”的距离。以可用高度为界，不再叠加最小高度和露出历史高度规则。头部和正文采用 flex/min-height:0，只有正文滚动。
- 下边缘与输入框外壳上沿留 10px，使用实际布局测量（如 ResizeObserver），不写死 composer 高度。打开后 composer 保留原输入框高度和外形，仅以只读提示替换可见内容，保留草稿及其布局尺寸；主 TodoDock/输入队列操作区在子阅读模式暂时隐藏，返回后恢复其状态。隐藏附属区、测量定位与开始动画依同一布局提交衔接，避免弹入后底边再跳动。该处理仅是展示建议，不删除待办或队列数据。
- 无遮罩，点外部不关闭。主历史露出的任务行仍可点击切换。不要把根阅读区全局 inert；仅遮住的区域自然不可指点，键盘阅读范围保持在子浮层，关闭或 Escape 可退出；不能把焦点送到被遮住的根消息控件。
- 建议背景 `#fff`、边框 `#e4e9f2`、圆角 12px，阴影复用 `0 10px 34px rgba(30,34,44,.14)`。使用局部层级约 26，低于 composer 30 和移动侧栏；实施时核对真实 stacking context，不仅比较数字。
- 头部常规高 44px，长标题省略但可获取全名；审批提示可增加一行并计入可用高度，不能硬挤图标。图标视觉约 28px，桌面点击区 32px；`pointer:coarse` 下点击区至少 44px，并相应允许头部增高。头部只放放大和关闭两个图标。
- 消息继续使用主会话字体、行高与工具样式。父气泡沿用 `#eaf4ff`、14px 圆角，小标签 `From parent`；每条父消息随正文滚动，不 sticky。
- child 消息区底部留白约 24px，覆盖根 `.ohb-stream` 的 144px 及 todo 模式 350px 补偿；避免将主输入框预留空间带入浮层。滚动条背景与白色浮层一致。

## 放大

占满主阅读区域，保留左侧导航；顶部面包屑用实际根会话标题和子任务标题，可点击根面包屑返回主会话，右侧只放缩小和关闭图标，不再增加独立返回按钮。主 composer 隐藏且不可聚焦，底部仅显示 `Read-only`。根内容保持挂载并隐藏/inert；不要给含有 child 的祖先设 inert。

子内容与浮层是同一 DOM/store，正文仍遵循 800px 列宽；窄屏变化使用消息锚点恢复阅读，不能只假设 scrollTop 永远准确。面包屑过长时截断中间标题，保留根返回入口与当前子任务名。

## 英文文案与图标

遵循 KISS：来源用 `From parent`，排队用 `Queued`，运行/终态使用必要的短状态。浮层下输入框提示 `Read-only subagent`，放大页仅 `Read-only`；审批提示仅用 `Approval required`，关闭浮层即可返回处理。已有位置或状态足以表达含义时，不再补一句解释。

放大、缩小、关闭使用图标；`Expand`、`Collapse`、`Close` 仅用于 tooltip 和 aria-label。关闭即回主会话，不在输入框、审批提示处再加返回按钮。面包屑直接使用实际会话标题，不重复加 `Main` 前缀。异常与缺历史确需说明时才显示短句。

## 动画与反馈

打开复用既有上滑淡入风格，位移约 18px、180ms、`cubic-bezier(.2,.8,.2,1)`；不从屏幕底端飞入。切换子任务不重复上滑；放大/缩小不做高度或逐帧布局动画。关闭可短淡出，不等待内容流结束。尊重 reduced-motion。

定位历史 prompt 后可用浅色轮廓/底色短暂提示约 1.2s，不闪烁。正文加载使用稳定骨架；不要先显示最新尾部再跳回旧 prompt。状态字号可较轻，但只读提示保持可读对比，不将整块统一降到 0.48 透明度。

## 历史导航

接近历史窗口下边缘时自动加载后续有界页，每次一个请求，不为填满历史而循环预取。缺口仍显示加载边界，失败时才提供 Retry。跳到最新仅用 ↓ 图标，tooltip / aria-label 为 `Jump to latest`，不用两个常驻文字按钮。

## 主会话审批占位

实际审批卡出现时，主 composer、TodoDock 和队列暂时隐藏且不可聚焦，保留组件状态。审批卡在主列底部留约 12px，按实际卡片高度给消息流预留空间；窄屏、多个审批和长内容不能压住最后一条消息。审批卡保留停止图标，避免隐藏输入区后丢失原停止入口。没有实际待审批项的同步错误不触发隐藏。
