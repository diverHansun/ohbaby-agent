# 用例与用户流程

| 用例 | 用户动作与结果 | 主要异常 |
| --- | --- | --- |
| UC-01 查看正在执行的委派 | 点击主历史任务行，浮层上滑出现，定位父消息；后续文字、思考、工具逐步更新 | 尚未接受时保留工具状态；读取失败可 Retry |
| UC-02 阅读历史委派 | 点击旧卡片，在同一逻辑子会话中定位那次父消息，前后可继续读 | 缺稳定锚点时说明不能精确定位，不猜测 |
| UC-03 切换子任务 | 点击另一个任务行，原浮层切换内容；每个子会话分别保存阅读与展开状态 | 迟到响应不得写入新查看器 |
| UC-04 放大与返回 | 点击 Expand，主阅读区变为子会话；面包屑显示关系；Collapse 回浮层，Close/Return 回主会话 | 宽高变化按消息锚点校正滚动，不清空正文 |
| UC-05 同子代理追加委派 | 父代理发出后续委派，被接受后立即出现 From parent 蓝色气泡和 Queued；启动后原地转状态 | 前轮失败导致队列暂停时保留 Queued 并提示等待恢复，不假装会立即启动 |
| UC-06 审批或停止 | 子窗口出现审批等待提示；用户 Return 后在主会话原入口操作 | 子窗口中不弹审批、不能 Stop；返回不会自动批准或终止 |
| UC-07 断线与恢复 | 保留已经读到的内容，显示 Reconnecting；恢复后续接最新权威状态 | 无法恢复时显示 Retry；旧缓存不能显示为最新状态 |

一次只有一个 child 视图。点击某条委派永远表达定位这次委派的意图；同一 child 在浮层/放大之间切换不产生新的定位。新任务启动、排队、完成只改变相应任务行，不能自动打开窗口。

主会话切换到另一 root 或 workspace 时关闭 child，取消相关请求和订阅。重新打开从权威数据恢复，不要求跨浏览器刷新持久保存阅读位置。
