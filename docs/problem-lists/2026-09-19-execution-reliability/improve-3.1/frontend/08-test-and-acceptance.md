# 前端验收

本页补充 [总测试标准](../04-test-and-acceptance.md)，不重复项目测试分类。

| 用例 | 实际浏览器需要证明 |
| --- | --- |
| UC-01 | `subagent_run` 是轻量行；点击后浮层上滑，底部距禁用 composer 约 10px；文字/思考渐进、工具及时变化，终态不重复结果 |
| UC-02 | 点击同一 child 的第二次历史委派，准确显示第二条 From parent；长历史查询有界；缺锚点给明确提示 |
| UC-03 | A→B→A 不叠窗、不串请求；各自工具展开保留；显式历史卡片定位优先；后台任务完成不抢内容 |
| UC-04 | 放大和缩小不重建消息树、不重播；正文/工具状态一致；根草稿和阅读位置返回后恢复；侧栏保留 |
| UC-05 | 忙时后续蓝色消息立即出现 Queued；当前轮输出归当前段；启动后同 ID 原地承接；取消/失败/暂停后的状态真实 |
| UC-06 | 子窗口审批不弹、发送/Enter/Steer/Stop 无效；Return 后原审批/停止可用；操作只作用当前根 |
| UC-07 | 流中断→重连→快照续传，文本无丢失/重复；旧分页不覆盖新流；绑定变化后旧数据不得泄漏 |

视觉检查同时覆盖 390px、720px 和常用桌面宽度，以及矮窗口与 200% 缩放。验证 float 下边缘在 composer 上方，长父 prompt 和长工具输出不横向撑开；只有正文内滚动，无 144/350px 根输入框残留留白。

键盘检查：打开焦点在标题，Escape 从放大回浮层再关闭；根面包屑直接返回；工具卡可键盘展开；Tab 不进入被遮住的根消息；关闭回触发项，失效项有安全回退；IME 和其他模态优先级正确。reduced-motion 下无强制上滑动画。

验收材料记录构建 commit、服务端/浏览器配置、确定性 fixture 与真实 LLM 场景分开，附必要截图或短录屏。纯组件快照不能证明布局尺寸，纯 HTTP 成功不能证明流式显示；规划期不制造“已通过”的结果。

文案专项：放大/缩小/关闭按钮仅显示图标，关闭承担返回主会话的作用，不重复提供返回按钮，tooltip 与 aria-label 完整；不把动作名再放到图标旁。输入框只保留 Read-only subagent 等必要短文案，不新增操作说明段落。
