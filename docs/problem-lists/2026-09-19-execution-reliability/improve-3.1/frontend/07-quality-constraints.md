# 质量约束

## 正确性与边界

root、逻辑 child、execution 和父消息身份分离；主消息流不接收 child 原始内容。Queued 不进入模型上下文。状态以已提交事实为准，不用前端计时器推断完成。只读 UI 不扩大任何服务端权限。

## 性能

详细订阅和 child 消息树各最多一个，复用 workspace SSE；历史有界分页和定位，不逐页搜索全量历史、不每次 token 重取快照。渲染按现有流式批处理节奏合并增量，保留稳定 key，避免整棵消息树逐 token 重挂载。

用长会话、多工具及快速输出测量浏览器，不为此预先引入虚拟列表或全局状态库。若实际测量发现不可接受卡顿，再针对热点调整。浮层重排不能随每个 token 重新测量输入框位置。

## 无障碍与适配

非模态 dialog 使用清楚的 accessible name；标题可程序聚焦，图标按钮提供 Expand/Collapse/Close 的 tooltip 与 aria-label，不在图标旁重复可见文本。提示不能仅靠颜色表达。不要逐 token aria-live 朗读正文，状态变化可 polite 通知。

只读说明保持足够对比；常规文字达到 WCAG AA 的对比目标，焦点可见。支持键盘、触屏、200% 缩放和 reduced-motion。输入法组字时不处理退出快捷键。窄屏或低高度以正文可滚动、不遮 composer 为硬约束，桌面图标点击区 32px，触屏（pointer:coarse）目标至少 44px；键盘焦点不落入被浮层遮住的根消息。

## 审批与错误可发现性

child 不弹审批，但不能让等待状态无提示；关闭或根面包屑可回到原根操作入口。读取错误局限在阅读区域，已有运行不被 UI 故障终止。断流保留内容并标记 Reconnecting，不展示虚假的 Completed。
