# 前端目标与职责

状态：improve-3.1 规划草案。用户确认来源见 [讨论](../00-discussion.md)，跨模块契约见 [总方案](../02-optimization-plan-and-change-scope.md)。

## 目标

用户从主会话里的一条委派快速查看子代理正在做什么，能够持续阅读文字、思考、工具和最终回答，并回到主会话继续操作。多次委派同一个子代理时，用户看到连续会话，而非多个孤立结果页。

## 职责

- 主历史保留轻量任务行；一个浮层承载完整过程，可放大到主阅读区域。
- 重用主消息渲染，维护定位、滚动、展开和切换体验。
- 从 SDK 消费权威状态，显示排队、运行、审批等待、终态及读取失败。
- 清楚表达只读边界，保存主会话草稿，把审批和 Stop 引导回主会话。

## 非职责

不调度子任务、不在前端推算执行终态、不往模型历史写入排队 prompt、不提供子会话编辑器或独立停止按钮。不重做整站主题、消息组件库、导航或窗口系统。TUI 保留现有 Ctrl+G 内部详情，本文只定义 Web。

## 成功标准

点击指定委派可找到对应父消息；生成过程逐步可见；切换视图不丢内容、不重播；新任务不抢阅读焦点；回到主会话时草稿和阅读位置保留。所有新 UI 文案使用简短英文，以间距和字重组织信息，少用点号分隔。常见操作用图标，英文动作名仅放 tooltip / aria-label。
