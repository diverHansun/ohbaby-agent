## 目标

主代理默认后台派遣子代理，可以继续独立工作；准备结束时，运行时自动等待本次任务的子执行。任意终态或用户 Steer 可以唤醒；首次等待最多 60 秒，继续等待每次最多 120 秒，到期带有限执行事实交还主代理判断，不自动取消子任务。普通消息继续排队。用户能独立看到子代理状态和完整只读子会话；主模型通过到期快照和增强后的 `subagent_status` 看到有限执行事实。本次结果交付处理后才允许正常最终完成。

不新增模型侧 `subagent_wait`、`subagent_read_result`、`subagent_read_history`。保留 `subagent_run/status/close`；长结果由运行时导出 `.output`，主代理按需用通用 read 获取。默认 stream 是会话对用户的输出方式，不能与后台派遣、内部完成等待混为一谈。

## 边界

- 本轮：本次任务归属、终态交付、有期限自动等待与状态/交付核对、有限执行事实及 `subagent_status` 增强、队列消息转 Steer、`.output` 生命周期与只读授权、用户子代理状态/只读过程、system prompt、Web/TUI/SDK 接线。
- 保持：SQLite 会话、独立 context scope、既有权限选择、显式 foreground、默认 TUI in-process 与 Web serve 的拓扑。
- 不做：运行中子代理主动协调/A2A、模型任意查询完整子会话历史、后台完成后默认另开用户任务、跨进程接管、完整重启恢复重写、通用文件工具增强。
