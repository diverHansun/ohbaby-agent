## 本轮目标

Stop 能中断当前任务树，普通排队消息随后自动推进；旧资源尚未清理时仍受保护。服务关闭有等待上限，`serve stop` 等待确认目标进程退出。重新启动后修复失主执行记录，不重跑旧执行；旧排队消息保留，用户逐条自行发送。恢复失败可明确定位到受影响会话，不再用永久 Thinking 掩盖错误。

2026-09-22 已确认：正常清理不新增前端通知；Stop沿第二轮D34提供原按钮等待反馈，可靠终态后结束，不等残留清理；清理异常实际阻塞新调用时，返回该调用的普通工具错误，原资源保护继续保留，不增加专门清理提示。工具 running 独立计时归第二轮，准入及异常清理判断归前置 C，第四轮组合验证。见[00 §0.4](00-discussion.md#04-2026-09-22静默停止工具计时与异常阻塞)。
