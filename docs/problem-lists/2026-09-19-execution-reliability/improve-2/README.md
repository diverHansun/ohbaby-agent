## 职责与前置分工

| 工作 | 归属 |
|---|---|
| 审批找得到、答得了、真实身份与一次性回答/撤销 | improve-1 |
| 整页快照与事件续传正确衔接 | improve-1.1 |
| 修复文件锁提前释放；明确文件/目录访问；主子代理及跨主会话并发；Bash 批次内保守调度、真实清理、来源限制 | 独立前置 C：C1 文件锁 → C2/C3 并发与清理 |
| 独立审批接线；结果逐项保存和展示，主代理等整批；等待/执行/清理事实；模型请求与 prompt 计时；保存失败中断和取消 | improve-2 |
| 子代理进展独立可见及结果可靠交付 | improve-3 |
| 全树 Stop、服务退出和冷恢复 | improve-4 |

前置 C 的确定规则：**已知文件按资源保护；未知残留 Bash 限制来源主会话及其子代理，其他独立主会话继续。** 第二轮消费这些事实和取消接口，不另造一套锁或清理执行器。不同主会话继续不代表任意 Bash 副作用已有文件隔离。

本轮默认工具行只提示执行和异常，精确状态放详情，不新增底部工具汇总；图标/动效的视觉细节另行讨论。Thinking 只在模型请求尚无正文时显示，每次请求重新计时，结束后轻量显示一次整轮总耗时。

不自动跳过受阻工具，不新增通用隔离框架。无法确认停止的操作仍可能阻塞冲突调用，批次尚未收齐时模型不能继续。
