前置 C 的确定规则：**已知文件按资源保护；未知残留 Bash 限制来源主会话及其子代理，其他独立主会话继续。** 第二轮消费这些事实和取消接口，不另造一套锁或清理执行器。不同主会话继续不代表任意 Bash 副作用已有文件隔离。

本轮默认工具行只提示执行和异常，精确状态放详情，不新增底部工具汇总。TUI 仅真实执行时转动并显示运行时间；Web 保留现有工具卡结构和 CSS 主体，仅对运行中文字增加轻量扫光，等待不动，遵守减少动态效果设置。Thinking 只在模型请求尚无正文时显示，每次请求重新计时，结束后轻量显示一次整轮总耗时。

Stop点击后在原按钮转圈并禁重复点击，可靠本轮终态到达才结束，不等残留清理；失败走现有错误提示。1秒仅是后端取消信号的本地响应目标，不要求RPC或按钮1秒完成。长等待可改原按钮提示，不新增状态栏，详见[02 §2.5](02-optimization-plan-and-change-scope.md#25-最小展示合同)及[04 T28](04-test-and-acceptance.md)。

正常资源竞争继续等待；清理失败或有限观察后仍未确认时，被挡住且尚未执行的调用返回普通资源错误，旧保护继续保留。整批逻辑结果收齐后模型继续，优先完成不冲突工作；确实无法继续就说明原因，不自行循环重试、轮询或反复kill。不自动重放工具，不新增通用隔离框架。
