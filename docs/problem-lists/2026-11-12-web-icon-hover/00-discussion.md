# 讨论记录与已确认要点

> 2026-11-12 起与用户逐项讨论，本文件随讨论更新。
> 议题：web 端可点击图标的 hover 反馈太重，要改轻。

---

## 1. 背景与动机

web 端很多纯图标按钮（关闭、复制、展开、侧栏开关等）在鼠标悬停时，会在 16px 图标外套一个 28px 的灰色圆角方块。方块面积比图标大很多，显得笨重。用户希望悬停时只让图标本身变化，最多在图标周围加很小的一圈底色。

侧栏在 `30965c23` 中已经先改成"只加深图标颜色"（`sidebar.css` 的 `.ohb-sidebar .ohb-icon-button:hover`），其他区域还没跟上。

## 2. 现状全景

逐条检查了 `apps/ohbaby-web/src/ui` 下 88 条 `:hover` 规则，并用 3 倍截图对比了悬停前后的效果。按类别分：

| 类别 | 现状 | 处理 |
|------|------|------|
| A. 纯图标按钮 | 整个按钮盒子出现 `--bg-hover` 灰色方块 | 本议题要改 |
| B. 输入框内带文字的控件（权限、模型、思考强度） | 整块胶囊或方块变灰 | 保留：底色和文字大小相称 |
| C. 列表行、菜单项、工具行、标签页 | 整行浅灰底 | 保留：行高亮本来就用底色 |
| D. 文字按钮、主按钮、危险按钮 | 底色变化 | 保留 |

A 类细分为三项：

- **A1**：公共样式 `.ohb-icon-button`（`shared/shared.css`），通过 `IconButton` 组件覆盖约 25 处。
- **A2**：各处手写的同类图标按钮，各自复制了一份方块样式。
- **A3**：顶栏上下文圆环 `.ohb-context-ring-button`，悬停时出现圆形浅灰底。

## 3. 参考项目对照

查了 `code-cli/` 下有 web 界面的项目：

- opencode、ZCode、claude-code、deepseek-harness、pi-web 都用"透明图标按钮 + 浅色方块"，和本项目现状一致。
- 只有 pi 只改图标颜色，不加底色。

"只变色"不是主流做法。本项目仍然采用它，理由是：

1. 图标平时是 `--text-dim`（`#71717a`），悬停后是 `--text`（`#18181b`），只靠颜色变化就足够明显。
2. 侧栏已经采用这种做法，全站统一成一种比两套并存更简单。

## 4. 已确认决策

| 编号 | 决策项 | 结论 |
|------|--------|------|
| A1 | 公共 `.ohb-icon-button` 的 hover | **只变色**：背景保持透明，图标从 `--text-dim` 加深到 `--text`。不用小圆形底色 |
| A1 | 侧栏的单独覆盖规则 | 公共样式改完后，`.ohb-sidebar .ohb-icon-button:hover { background: transparent; }` 变成多余，删除 |
| A1 | 键盘焦点 | `focus-visible` 焦点环保持不变，不能因为去掉方块而让键盘用户看不到焦点 |
| A2 | 手写的同类图标按钮（横幅关闭、目标条暂停/编辑、排队消息编辑/删除、上下文弹窗关闭、归档页删除） | 本轮不动，保留各自的方块底色 |
| A3 | 顶栏上下文圆环 | 保留浅灰圆底：圆底和圆环一样大，不算笨重 |
| B | 输入框内带文字的控件 | 保留底色：带文字的胶囊，底色和内容大小相称，不是“小图标套大方块” |

## 5. 讨论日志

- 2026-11-12：盘点 88 条 hover 规则，分出 A/B/C/D 四类。用户确认 A1 改为只变色。
- 2026-11-12：用户确认 A2 不动、A3 保留圆底、B 保留底色。本议题只改 A1。

## 6. 实施记录

- `shared/shared.css`：`.ohb-icon-button:hover` 去掉 `background: var(--bg-hover)`，只保留 `color: var(--text)`。`transition` 里的 `background` 保留，归档页删除按钮等仍有自己的底色变化。
- `sidebar/sidebar.css`：删除 `.ohb-sidebar .ohb-icon-button:hover { background: transparent; }`。
- 浏览器走查（`vite` mock 场景 `typical`）：悬停顶栏 `Open side panel`，计算样式为背景透明、颜色 `rgb(24, 24, 27)`（`--text`）。全局 `:focus-visible` 焦点环规则未变。
- `apps/ohbaby-web` 全部 952 项测试通过。
