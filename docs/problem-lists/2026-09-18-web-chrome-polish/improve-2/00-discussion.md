# 讨论记录与已确认要点

> 2026-09-18 形成初稿；2026-09-19 按用户最新确认修正权限图标。正式方案见 01–04。
> 来源：improve-1 落地后的 chrome 跟进。同一落点 `2026-09-18-web-chrome-polish` 的 improve-2。

---

## 1. 背景与动机

输入框离窗口底还有空间，却被下面两颗 `auto mode` / `default` 胶囊挡住，边缘感重。侧栏开关是瞬间装卸。顶栏和会话列表过白。header 黑色大写 `OHBABY` 和空态黄粉蓝圆角字标不是同一张脸。

## 2. 已确认：目标与范围

| 决策项 | 结论 |
|--------|------|
| 文档落点 | `docs/problem-lists/2026-09-18-web-chrome-polish/improve-2/` |
| 轮次触发 | 主动切割 / 跟进（improve-1 把这些划出；用户在落地后单独立轮） |
| 关键改动清单 | **不写** |
| mode 按钮 | **去掉**。`Shift+Tab` 仍切换；默认 auto |
| mode 提示 | **不用字、不用点、不用胶囊。** 只用输入框描边：auto = 中性浅灰边；plan = 浅黄边 |
| 权限 | 收进输入框内底栏左侧，轻量 icon。default = **灰色手**；full-access = **红色盾牌+感叹号**。hover 有浅边线，键盘 focus 有可见焦点环。点击仍两态循环 |
| 输入框尺寸 | **只加输入框**：加宽、加高。阅读列仍 720px |
| 输入字体 | 框内字和未输入占位（含打字机）**轻微缩小** |
| 下移 | 去掉底栏胶囊后，输入框整体贴底（底 padding 收到约 10–12px） |
| 侧栏 | 继续**推进**正文，只补轻量 CSS 动画 |
| header 字标 | **拿掉四色小点**，只留与空态一致的三色小写 `ohbaby` |
| 玻璃 | header 和侧栏会话列表浅玻璃，贴近正文 `#fafafa`，不要重毛玻璃 |
| 参考图 | 第三张只参考「控件在框内底栏」的布局，不把图中 `+`、High、麦克风等控件加入产品；权限两枚图标按用户文字要求设计 |

## 3. 已确认：板式

```
header:  [oh baby 三色小写]          idle | 模型 | 环 | goal?
         浅玻璃；无 2×2 点；高度仍约 44px；不与侧栏顶对齐

sidebar: 推进 300px ↔ 0，约 200ms；浅玻璃列表

composer（比阅读列宽，约 800px；贴底）:

  ┌─ auto: 浅灰边 / plan: 浅黄边 ──────────────┐
  │  略小的占位或正文                           │
  │  [手/盾]              [🧠 unknown] [○]     │
  └────────────────────────────────────────────┘

无：auto mode 胶囊、default 胶囊、框外底栏
```

读屏：输入框带 `aria-label`（或等价）标明当前 mode 与 permission，因为描边颜色对辅助技术不够。脸上仍然没有 mode 字。

## 4. 已确认：边界（不做的事）

| 项 | 本轮不做 |
|----|----------|
| TUI | 零改动 |
| 阅读列加宽 | 用户只要输入框加宽 |
| 侧栏改成盖在对话上 | 继续推进 |
| 侧栏顶与 header 齐高 | improve-1 已否决，本轮不翻案 |
| 参考图里的 + / High 下拉 / 麦 | 不进产品；本轮也不加入模型切换或语音能力 |
| 改 `canSend` / 队列 / abort / pairing / PermissionModal | 只改脸上的入口 |
| 空态 70px 大字标重画 | header 缩小复用同一套字母和颜色 |
| “Ask Lychee” 文案 | 只改字号 |
| 像素视觉回归、必做 Playwright | 浏览器看一眼 |
| 关键改动清单 | 用户明确不要 |
| 本规划会话写代码 | 审查后再实施 |

## 7. 用户确认记录

- 2026-09-18：mode 用框边颜色分 auto（浅灰）/ plan（浅黄）；不要 mode 按钮。
- 2026-09-19：default 使用灰色手形 icon；full-access 使用红色盾牌叹号 icon。
- 2026-09-18：只加宽、加高输入框；框内字和占位略缩小。正文列不加宽。
- 2026-09-18：侧栏继续推进，只补动画。
- 2026-09-18：header 拿掉小点，只留字。
- 2026-09-18：不要关键改动清单；写 improve-2 文档并自检。

实施参数建议：输入框目标宽约 800px、框内字 14px / 行高 22px、侧栏动画约 200ms；这些数值需在浏览器中按实际布局验收，不视为用户逐项确认的固定值。
