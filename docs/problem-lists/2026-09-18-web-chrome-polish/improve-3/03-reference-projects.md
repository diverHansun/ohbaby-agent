# 3. 截图参考与取舍

> 本轮附件包括 Codex 完整访问确认卡、Codex 对话布局和 OpenCode 工具调用行。学信息层级与交互，不抄产品名。

---

## 3.1 截图分别说明什么

| 来源 | 可观察内容 | 用于本轮 |
|------|------------|----------|
| 当前实现 | `+ New session` 的固定最小宽度与 margin 叠加；usage 为空时圆环不挂载 | 定位裁切与圆环缺失原因 |
| 用户说明 | 方框 + 笔的新建图标 | **只学图标**，不改英文文案 |
| 附件 | Codex 确认卡：警示标题、风险说明、能力范围、两颗操作按钮 | 学「先问再开完整访问」的信息层级 |
| Codex 对话截图 | 用户消息为右侧浅蓝气泡；Agent 内容无气泡、位于阅读列 | 建立自然问答层级 |
| OpenCode 截图 | 工具调用接近正文行，默认弱化；披露箭头表达展开状态 | 去掉工具卡片感 |

## 3.2 可借鉴点

| 来源 | 做法 | 为何相关 | ohbaby 取舍 |
|------|------|----------|-------------|
| 用户说明 | 方笔图标、无描边、文字在图标右侧 | 用户指定替换 `+` | **Adopt** `SquarePen`；**Reject** 把文案改成「新建会话」 |
| 附件 | 圆角白卡、标题提问、灰字说明风险 | 用户要提醒卡 | **Adapt** 成更紧凑的 ohbaby 文案与两键「Not now / Use full access」 |
| 附件 | 权限能力大面板 | 能解释危险范围，但占用较大 | **Reject** 大面板；用一段短文交代命令、网络、文件风险 |
| Codex 对话截图 | 右侧用户气泡 + 无气泡 Agent 回复 | **Adopt**；不复制其反馈按钮和模型元信息 |
| OpenCode 工具行 | 紧凑摘要与右侧披露箭头 | **Adapt** 为 hover/focus 显示箭头、展开后分离 Input / Output |

## 3.3 明确不借鉴

| 图中元素 | 本轮取舍 | 原因 |
|----------|----------|------|
| 「新建会话」中文 | 不改 | Web chrome 其余是英文；用户没要求翻译按钮 |
| Ultra、Codex、深度推理 | 不出现 | 不是本产品能力捆绑 |
| 把「继续」当主按钮 | 不用 | 与「默认使用完整访问权限」冲突 |
| 工具审批四键配色 | 不复用到这张卡 | `permission-button` 规格管的是另一件事 |
| 顶栏改成细进度条 + `32k/200k` | 不用 | 用户要圆环；读数留在 tooltip/popover |

## 3.4 对 02 方案的影响

- Stage 1 的图标来自用户说明，布局修正来自当前实现的盒模型。
- Stage 2 恢复的是已有 `ContextUsageControl`，不是新控件。
- Stage 3 的信息层级来自附件，文案、默认按钮、与 PermissionModal 隔离来自 00。
- Stage 4 采用 Codex 的消息层级，但暂不加入 Lychee 品牌图标。
- Stage 5 采用 OpenCode 的轻量工具行；失败摘要静默是本产品单独确认的规则。
