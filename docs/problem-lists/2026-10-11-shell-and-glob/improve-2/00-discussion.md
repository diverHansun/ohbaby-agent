# 讨论记录与已确认要点

> 来源：2026-10-11 当前会话。网络契约见 [improve-1](../improve-1/00-discussion.md)，本批不另行决定代理来源。

## 已确认的 Shell 行为

| 项           | 结论                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| 执行         | 真实系统 Shell 执行原始命令，不改写命令、不因执行失败切换解释器重跑        |
| 分析         | 使用成熟解析器；分析不完整不能直接判成语法错误                             |
| 结果区分     | 语法诊断见原始 stderr；分析不完整、权限不允许、执行失败分别表达            |
| default 审批 | 分析不完整时，整条命令一次审批；不生成宽泛长期放行规则                     |
| 子代理       | 与主代理共用审批规则，TUI / Web 主会话同一入口处理                         |
| Windows      | 优先 PowerShell 7，缺失时使用 Windows PowerShell；显式配置支持的解释器优先 |
| macOS        | 尊重用户已有 bash / zsh 配置，无明确配置时用系统默认                       |
| Linux        | 尊重用户配置，使用可用系统 Shell                                           |
| 配置错误     | 用户明确指定的解释器找不到时直接报错，不悄悄换解释器                       |
| 工具兼容     | 暂保留 `bash` 工具名；说明实际解释器；不增加每次调用选择 Shell 的参数      |

## 已确认的 Glob 行为

| 项          | 结论                                                                 |
| ----------- | -------------------------------------------------------------------- |
| 引擎        | 复用已打包的 ripgrep，不新增 fd 或另一套匹配库                       |
| 相对路径    | `*.ts` 仅搜索根层，`**/*.ts` 递归                                    |
| 隐藏文件    | 继续包含                                                             |
| 固定排除    | 保留 `.git`、`dist`、`node_modules`、`out`、`target`                 |
| ignore 文件 | 本批不引入 `.gitignore` / `.ignore` / `.rgignore` 搜索范围变化       |
| 符号链接    | 不自动跟随搜索目录内部的符号链接                                     |
| 改进目标    | 常用模式匹配正确、取消有效、正文和模型 metadata 如实说明搜索是否完成 |
| 暂不增加    | 分页、修改时间排序、新的搜索工具                                     |

## 工程解释

用户要求区分错误来源，不等于要求新增统一 `syntax_error` 字段。本批保留系统 Shell 的真实语法诊断，分析不完整和权限拒绝使用各自明确的路径；不凭 AST 错误或退出码猜测语法错误。`SHELL` 的继承偏好与本平台支持的原生路径在 02 区分，防止把 fish / MSYS 环境误当无效的 ohbaby 专有配置。
