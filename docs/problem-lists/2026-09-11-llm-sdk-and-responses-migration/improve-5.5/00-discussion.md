## 0.4 已确认的非目标

不建设完整 Responses 所有能力；不加入 hosted tools、previous_response_id、Conversations、服务端状态依赖或后台任务。不修改 system prompt 组装、缓存前缀、cache_control、key、TTL，不重新设计压缩阈值、EMA 校准公式或工具调度。

不新建 reasoning 计费引擎、不新增所有 HTTP 尝试账本、不将子代理或辅助请求用量合入主界面 cache。消息原生状态需要恢复，与 cache 进程内累计的生命周期分开。

K14（范围与估算）：本轮主体是推理配置与原生状态保存、恢复、回传；improve-1～5 回归在 F 批，不把 D/E 原生接续称为“只做回归”。不透明状态的估算采用 reasoning 子项、总 output、请求 max output 的回退顺序，每个响应只取一次；可能保守地提前压缩，不能当成真实 token 或二次加入 usage。实施报告须展示验证结果。
