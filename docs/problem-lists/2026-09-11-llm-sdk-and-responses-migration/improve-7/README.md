## 本轮约束

- 三协议共用既有循环与自有消息结构；工具业务失败作为结果交给模型，运行取消和框架故障分别处理。
- 请求结束、结果保存、运行结束各有含义；复用现有字段，不新增重复状态体系。
- SDK 重试及项目现有重试配置保留，明确次数叠加与观测限制。已有有效输出后不自动重发；不增加自动续写。
- 历史原始记录与可发送材料分开；错误协议消息不能直接重放，允许的正文仅作有说明的纯文本投影。取消正文不回传，已完成工具事实继续保留。
- 保留压缩/prune 算法、旧摘要策略和完整模型窗口 95% 自动压缩规则；只补影响统计或语义交接的最小修复。
