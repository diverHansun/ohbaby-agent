# 长会话翻不到历史消息

2026-11-20 开启。已实施，待审核。

长会话里往上翻，看不到压缩前的旧消息。页面顶部只有一个 `Load earlier messages` 按钮，点了以后拉回来的是空消息，还在页面上撑出一大块空白。这里有三个问题：前端滚到顶不会自动加载；后端历史接口把已压缩的正文过滤掉了；空消息也占着行间距。本议题前后端一起修。后端定一条规则：已压缩只决定发给模型什么，不决定给人看什么。前端改成上滑自动加载，加载时只显示一个小 spinner。

## 范围

- 后端：UI 投影一律显示原文，压缩标记只影响发给模型的上下文。分叉点的判断同步放开，旧回答也能分叉；复制历史时压缩标记按摘要是否一起复制来去留。保存思考内容时，只在消息不在热窗口里才发“历史失效”。
- 前端（Web）：上滑接近顶部时自动加载上一页，加载中只显示小 spinner，去掉按钮和全部文字；失败时不提示，下次上滑时自动重试（子代理详情原有的错误条保留）。只有游标真的往前走了才自动接着拉。会话运行中往上翻，消息只是被挤出热窗口时，已经翻出来的旧消息不会被清掉。空消息不再占位置。压缩分隔线之前的用户消息不显示编辑按钮。
- 主会话、Side Chat、子代理对话共用同一个消息列表组件，改一处，三处同时生效。
- TUI：代码不改，只做验收。
