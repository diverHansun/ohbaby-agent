# 0. 讨论与已确认要点

> 本文记录 2026-11-24 讨论后确认的结论，被否决的方案不再展开。

## 0.1 用户提出的问题

弹出审批卡片时，侧边栏当前会话的行尾会出现一个黄色小点，表示在等用户操作。用户觉得这个点有三个问题：

- 颜色不对，偏橙偏深，不像"等你操作"的提示色。
- 位置不对，hover 时会被「…」按钮挡住。
- 用户最初以为是会话时间挡住了它，实际原因见 0.2。

## 0.2 现状核实

- 圆点在 `SessionRow.tsx` 的 `.ohb-session-meta` 里，和相对时间二选一：等待审批时显示圆点，否则显示时间。所以时间和圆点不会同时出现。
- 挡住圆点的是 hover 时出现的「…」按钮。它绝对定位在 `right: 4px`，圆点也贴着行尾，两者重叠。
- 圆点颜色用的是全局 `--warning: #d97706`。
- 只有当前打开的会话会被标成等待审批（`AppController.tsx` 只给 `activeId` 打标）。这个问题另开议题处理。

## 0.3 已确认的决定

| 编号 | 决定 |
|---|---|
| C1 | 只做 Web。侧边栏只在 Web 里有 |
| C2 | 圆点挪到左侧前导列，也就是"运行中"点阵所在的那一列，在文件夹图标正下方。"运行中"和"等待审批"在代码里互斥，同一列不会冲突 |
| C3 | 圆点在会话行内上下居中，在前导列里左右居中 |
| C4 | 颜色用 `#F2C230`（偏黄的橙黄）。新增专用 token，不改全局 `--warning`，因为警告横幅等地方还在用它 |
| C5 | hover 时圆点保持可见。它在左侧，和右侧的「…」、pin 按钮不会重叠，hover 时也不会位移 |

## 0.4 按默认处理（讨论中未提异议）

- 圆点大小保持 7px。
- 保留 `role="status"` 和 `aria-label`。原计划另加 `title`，实施时发现前导列是 `pointer-events: none`，悬停提示出不来，所以去掉。
- 移动会话时，前导列优先显示移动中的 spinner。
- 子代理列表里"等待审批"的圆点（`StatusGlyph`）一起换成新 token。它的注释写明要和侧边栏同色。

## 0.5 明确不做

- 不让非当前会话显示圆点。这需要服务端推送每个会话的等待状态，单独开"跨会话等待状态"议题。
- 不改全局 `--warning` 的颜色。
- 不在 hover 时隐藏圆点，也不把它换成文字徽标。
