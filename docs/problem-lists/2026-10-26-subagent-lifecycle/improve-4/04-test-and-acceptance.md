> 实施验收要求，不是已通过的测试报告。"来源"一列是拆分前在 improve-1 里的编号。

## 4.2 合并门槛

1. I4-01 到 I4-05 都有对应证据。
2. `pnpm typecheck`、`pnpm lint`、受影响的测试、`pnpm test:smoke` 和 `pnpm test:e2e:compiled-web` 通过。
3. 只剩一套子代理详情入口。
4. 人工走查宽屏和窄屏：工具输出 → 启动链接 → 右侧详情 → 返回 Active/Done 列表 → 切换代理 → 主会话继续输入；关 Tab 后子代理继续；关闭实例后它从列表和主会话入口都消失。
5. **对抗性复查：** 持久历史还在，但旧的列表缓存和主会话旧链接都不能让 UI 重新显示已关闭的实例。

实施完成后在本目录写 `05-implementation-acceptance.md`。
