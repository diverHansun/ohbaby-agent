# 4. 测试与验收：右侧 Tab 容器与子代理阅读（前端）

> 实施验收要求，不是已通过的测试报告。Web 测试规范见 [Web 测试规范](../../../ohbaby-web/test.md)。"来源"一列是拆分前在 improve-1 里的编号。

## 4.1 验收项

| ID | 来源 | 场景 | 必须观察到的结果 | 主要层级 |
| --- | --- | --- | --- | --- |
| I3-01 | 原 A24 | 第一次展开右侧栏；添加、关闭 Tab；收起再展开 | 默认显示入口页；Subagents 是独立 Tab；只提供能用的页面；恢复已开的页面；没有文档、Review、浏览器、终端的占位页 | Web component + compiled E2E |
| I3-02 | 原 A27（Web 部分） | 多个实例跨轮运行；列表刷新失败 | 一实例一行；Active/Done 分组正确，中断和失败在 Done 但不显示成功；等审批和收尾中在 Active；刷新失败不清空；显示未处理消息条数 | Web integration |
| I3-03 | 原 A28（Web 部分） | 从列表打开一个已经续跑过、还在运行的实例 | 标题和列表显示实例的当前状态；新消息实时可见。带锚点打开（定位到历史位置）要等 improve-4 的主会话入口，在 I4-02 验收 | Web integration + 人工检查 |
| I3-04 | 原 A26（停止按钮部分） | 主代理空闲时、主代理正在前台等待这个子代理时，分别在详情里点停止；执行已换新后点了旧页面上的停止 | 只停指定实例，主代理和兄弟不受影响；迟到点击不误停新执行；按钮状态跟随回执 | Web integration |
| I3-05 | 原 A30（Web 部分）、原 A29（详情部分） | 关闭 Subagents Tab；收起侧栏；切换主会话；正在看的实例被 close | 关 Tab 和收起只取消读取，子执行继续；切换会话不串数据；重新打开读到真实的当前状态；被 close 的实例从列表消失，详情退回列表 | Web integration + compiled E2E |
| I3-06 | 原 A31 | 长会话分页、断线重连、展开工具、滚动位置；窄屏和键盘操作 | 保留现有阅读能力；列表和详情来回切换不丢阅读位置；没有模态焦点锁，能回到主会话；主输入框照常可用 | Web integration + 人工检查 |

## 4.2 测试方法

保留现有的分页、迟到事件、revision 和阅读缓存测试，只改被新布局替代的断言。旧浮层的测试这一批不动。

## 4.3 合并门槛

1. I3-01 到 I3-06 都有对应证据。
2. `pnpm typecheck`、`pnpm lint`、受影响的 Web 测试和 `pnpm test:e2e:compiled-web` 通过。
3. 旧浮层和主会话派遣记录的行为不变（improve-4 再改）。
4. 人工走查宽屏和窄屏：入口页 → Subagents 列表 → 详情 → 停止 → 返回列表 → 切换实例 → 关 Tab，子代理继续运行。

实施完成后在本目录写 `05-implementation-acceptance.md`。
