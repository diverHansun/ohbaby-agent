# 2. 优化方案与改动面：右侧 Tab 容器与子代理阅读（前端）

> 2026-10-29 按 D46 从 improve-1 拆出。讨论记录在 [improve-1/00](../improve-1/00-discussion.md)（主要是 D10–D12、D36–D40、D46），现状见 [improve-1/01](../improve-1/01-problem-analysis-and-current-state.md) 的 P8。
> 前提：improve-2 的接口类型已经确定。改动只在 `apps/ohbaby-web`。

## 2.1 目标与范围

新建右侧栏：Tab 容器、默认入口页、Subagents 列表和实例详情。这一批只"新建"，旧浮层和主会话入口的切换留给 improve-4。

这一批只有 Subagents 这一种页面。文档查看、Review、浏览器、终端都不做，也不放用不了的占位页，不做浏览器地址栏或网站推荐。

## 2.2 容器

- 主区右侧加一个能展开、收起、调整宽度的区域。顶部有 Tab、关闭 Tab、添加页面按钮和侧栏开关。
- 第一次展开、还没有打开任何页面时，显示一个轻量入口页，提供"子代理"入口。已经开过页面的，恢复当前 Tab。
- "添加页面"只列出这一批真正能用的页面。
- **Tab 状态只放前端（D46）。** 用一个简单的页面类型 union（这一批只有 `subagents`）加局部状态管理，不建插件注册框架。以后加终端、浏览器，就是往 union 里加类型，再接各自的后端。ZCode 的 `workspaceSidePane.ts` 就是这么做的。
- Tab 用独立的 `tabId`，不把页面类型当全局唯一键。这一批不把每个子代理各开成一个顶层 Tab。

## 2.3 Subagents 列表

- 数据来自 improve-2 的实例列表快照。一行对应一个未关闭的实例，显示名称、实际状态、简短任务说明和时间。
- 按 Active/Done 分组，分组在前端根据状态推导：
  - **Active：** 正在执行、正在启动、还在收尾，以及等审批的。
  - **Done：** 已完成、已中断、失败、超时，并且已经收尾完毕的。
- 具体的状态标签照样显示，Done 不等于成功。空分组显示空态。closed 的实例不属于任何分组。
- 有未处理消息时（D45），显示"有 N 条消息未处理"。

## 2.4 详情

- 点击实例，在同一个 Tab 里进入它的子会话。顶部有：返回列表、稳定名称、当前状态，运行中时还有"停止"按钮。
- **停止按钮**调用 improve-2 的单实例停止接口，带上当前看到的 execution 身份。主代理空闲、正在运行或正在前台等待时，这个按钮都能用。
- 详情只读。用户通过主会话安排后续工作，不给子代理加输入框。
- 保留现有的阅读能力：消息、工具参数和输出、保存的 reasoning、分页、实时更新、阅读位置。复用 ConversationStream、消息展示组件、reader 和缓存，不再写一套。
- 列表里按 `subagentId` 选择。从主会话历史进来的入口（improve-4）额外带可选的 `anchorExecutionId`；定位到历史位置，不影响标题显示的当前状态。

## 2.5 关闭、切换与窄屏

- 关 Tab 或收起侧栏，只释放读取用的 watch，不调用 agent 的 close 或 stop。
- 切换主会话时，清掉旧的选择，隔离缓存和事件，不把别的会话的子代理带过来。
- 实例被 close 后：从列表移除；如果正在看它的详情，退回列表。
- 窄屏时，右侧阅读区占满可用宽度，同时保留明确的"返回主会话"入口。这只是布局变化，不暂停运行，也不禁用后台输入。
- 键盘焦点按普通侧栏处理，不沿用旧浮层的模态焦点锁。
- 打开右侧详情不影响主输入框和主会话运行。

## 2.6 与旧浮层共存

improve-3 合并后、improve-4 合并前，旧浮层还在，主会话里的派遣记录仍然打开旧浮层。这段时间会同时存在两个详情入口，D46 已确认可以接受。新的右侧栏只能从入口页或"添加页面"打开。
