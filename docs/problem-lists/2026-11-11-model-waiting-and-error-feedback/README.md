## 范围

- 补齐可恢复的重试等待事实，保持同一模型步骤的等待反馈连续。
- 对齐 provider 错误归一化，主会话和 Side Chat 共用轮次内错误展示。
- Web 与 TUI 都把错误作为简短的轮次结果保留，不提供关闭；Web 断线约 10 秒后显示全页静态遮罩。
- daemon 连接反馈区分短暂重连、持续断开和会话同步；主会话与 Side Chat 对齐，TUI 复用已有 daemon 连接机制。
- 保持现有重试预算、部分输出保护、工具执行和审批边界。

不重做通知系统，不修改 Side Chat、Fork、Rewind 的后端业务规则，不增加自动续写或部分输出后的自动重放。
