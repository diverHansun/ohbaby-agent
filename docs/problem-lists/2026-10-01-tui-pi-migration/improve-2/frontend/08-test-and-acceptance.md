# improve-2 前端：行为与视觉验收

这是未来验收清单，**不是测试通过声明**。测试工程规则、命令和 Stage 门统一见 [本轮 04](../04-test-and-acceptance.md)，不复制第二份编号体系。

## 1. 用例验收

| 用例 | 用户可观察完成结果 | 对应工程用例 |
| --- | --- | --- |
| UC-INPUT-01 | 完整字素可编辑，长文可到达；按一次 Enter 发一次原文；准备/同步不丢稿 | I2-T02–T05、T07–T08 |
| UC-DRAFT-01 | A/B 草稿和光标互不覆盖；审批返回不改变原文；旧响应不清新输入 | I2-T06–T08 |
| UC-QUEUE-01 | 正确 lease 才保存，取消还原完整原草稿；未知重发保持第一次意图 | I2-T09–T10 |
| UC-PERMISSION-01 | 来源与范围明确，全文可达；无 deny 的 Esc 不提交；失败/过期不假成功 | I2-T11–T13 |
| UC-TASKS-01 | 运行默认展开、手动收起保持、确认停止隐藏且可回看；总数真实、续行对齐、全文可达；不挤坏主交互 | I2-T01、T14–T15 |

## 2. 测试分层

纯 reducer/计数用 unit，单面板输入/状态用 contract，实际 App/recovery/SDK 协作用 integration，终端行为用 FakeTTY＋真实 Ghostty。复用 [06 场景](06-data-api-and-state.md#5-可控场景与复用)；不以大量快照替代操作与 payload 断言。浏览器/Playwright 不作为 TUI 主验收工具。

## 3. 必须覆盖的异常组合

准备中切会话后旧模型查询返回；已发送但回执丢失同时键入新草稿；lease 过期后切回；审批同 ID 新 epoch；无 deny 按 Esc；sending 连按 Enter；长正文读到末页后 resize；审批与子代理浏览器先后到达；进行中 Tasks 多项且长行；停止请求失败/确认终态、Goal 连续 run、子代理结束、断线未知、停止后回看。对应 04 的每种不可提交状态都要证明没有请求副作用。

## 4. 视觉走查

| 区域/fixture | 尺寸 | 检查点 |
| --- | --- | --- |
| Prompt / unicode-draft、long-draft | 120×40、80×24、60×20 | 字素光标、窗口范围、底栏稳定、正常文本不刺眼 |
| Queue / lease-expired、receipt-lost | 80×24、60×20 | 原文保留、错误/下一步明确、没有假“保存成功” |
| Permission / long、no-deny、expired | 120×40、80×24、60×20、80×12 | 来源/范围/选择层次；全文可达；键提示真实；尺寸不足不误提交 |
| Tasks / many、多 in_progress | 80×24、60×20 | 计数、当前项、续行和展开可达性，停止隐藏/手动回看，无意外抢焦点 |
| 组合 / long-history＋上述交互 | 80×24、80×12 | 原生上滚、复制、焦点往返、无变化时输出安静 |

每类在深浅背景和低色彩抽查，活动动画关闭再检查一次。验收按 [03 §7](03-ui-layout-and-style.md#7-视觉验收口径) 判断结构与可读性，不做像素级追逐。若文字尺寸初值调整合理，可记录为实现调整；改键义/丢原文/扩大授权是缺陷。

结果统一进入实施后的本轮 05；缺真机证据就明确未验收。子代理与 Pi 的计划审查不能替代以上产品验收。
