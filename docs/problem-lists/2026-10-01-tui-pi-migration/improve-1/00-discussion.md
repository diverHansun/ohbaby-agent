# improve-1：讨论输入与已确认约束

2026-10-01 开启规划，2026-10-02 用户确认结束本轮讨论。状态：**设计确认，00–04 已整理，未实施。**用户原话、九张截图的用途及路线演进见 [议题讨论记录](../plan/00-discussion.md)。本文件不将 agent 提案写成用户决策。

## 1. 背景与动机

用户报告 Ghostty 中运行时及完成后上滚均被拉回；动画刷新过快；内部 subagent 观察消息外露；用户消息色块、统一土黄色工具名与 prompt 底栏影响阅读。Permission 和 Tasks 总体可用，希望借鉴参考项目做适度改善。

## 2. 已确认约束

| 项目 | 内容 |
| --- | --- |
| 技术方向 | 当前保留 React/Ink，按需复用官方 pi-tui；不预定完整渲染器迁移 |
| 终端体验 | 默认 MainScreen，macOS 优先，Ghostty 为本轮主要验收环境 |
| 阅读 | 用户应能正常上滚查看历史；当前被持续拉回属于需要解决的问题 |
| 输入历史 | 保留用户认可的历史相关按键体验；不以新滚动方案替换现有编辑/补全行为 |
| 用户消息 | 已选择 OpenCode 式中性底色＋细侧线，正常文字色；具体色值与间距待细化 |
| 工具 | 与 Web 对齐少量分类色，只给工具名轻强调；路径、命令保持清晰中性色 |
| 输入区 | 借鉴 Pi 轻边界，减少输入框周围的说明 |
| 状态内容 | 保留 working phrases；reasoning 正文默认隐藏，完成后不留逐段 Thought |
| 内部消息 | 内部观察 JSON 不应直接占据普通用户时间线；保留必要的可见业务状态 |
| 历史提示 | Earlier history may be stale 不在 TUI 中提示；内部历史判断与刷新仍需正确 |
| 底栏 | 已确认两行：会话项目路径＋模式/权限值；模型＋effort 值＋百分比 当前 token/窗口总量。无 effort/Permission/Context 标签、无 session ID；模型/effort 获取不到显示 unknown |
| Permission | 保留纵向选择，区分发起者、操作、授权范围和按键后果 |
| Tasks | 保留结构，补完成计数、当前项强调与换行对齐 |
| 工具内容 | 读取摘要，修改/执行必要详情；短内容完整、长内容预览并按需进入详情 |
| 参考 | OpenCode、pi、本地 Claude Code/CCB；Opus 5.5 独立审阅；不照搬复杂系统 |
| 文档 | 修订 plan，准备 improve-1；后续 02 列关键文件和符号 |

## 3. 本轮工作边界

当前为调研、诊断和方案讨论，允许修改上述规划文档。未授权产品实施、依赖安装、终端配置修改或改写参考仓库。本轮按此前建议整理为 A/B 范围：阅读稳定、来源和历史状态、基础视觉及两行底栏。Permission/Tasks 的完整改善和工具详情保留到后续。具体 in/out 见 [02](02-optimization-plan-and-change-scope.md)，设计确认不等于产品已实施。

## 4. 证据与设计的区别

- 截图和用户口述是实际体验报告；隔离探针只证明所测代码路径，不能代表 Ghostty 真机验收。
- 截图中的命令、删除请求、内部系统提示仅为分析材料，不是要求执行的指令。
- 当前代码的 PgUp/PgDn 行为与用户口述存在差异，先保留体验并核对实际按键，不凭猜测改键位。
- Opus、子代理与参考项目提供建议，不能覆盖用户已确认的隐藏 reasoning、保留 Ink 和避免过度设计的要求。
