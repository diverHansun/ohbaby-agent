## 视觉方向与实现调整

保持单列终端时间线：工具名使用类别 token，对象及正文普通色；错误独立用文字和错误色。没有卡片背景、详情页、每条快捷键教程、新 spinner 或额外常驻底栏。

采用 Opus 5.5 的小幅设计建议：标题按真实显示列缩写，长路径保留可辨对象；紧凑 diff 的不相邻 hunk 有省略分隔，行号列宽一致；源头限制与前端预览省略分开；恢复提示收敛到文档确定的状态。新建 Write 即使有 diff 也优先显示内容。Markdown 行内代码保留反引号，避免低色彩下只靠颜色辨认。

预览初值沿原方案：Bash 命令最多两行，输出尾部五行；Write 新建和 diff 约十个显示行。省略计数基于排版后的显示行；错误始终有可见依据。pi 的代码块与 blockquote 采用其文本排版，未保留旧自制 Markdown 解析路径。
