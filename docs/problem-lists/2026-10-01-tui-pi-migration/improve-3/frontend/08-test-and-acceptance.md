## 2. 测试分工

纯文本/预览/diff 使用 unit；键位和 SDK 数据使用 contract；执行事实经过持久化与 UI 使用 integration；终端 raw mode、回滚、复制、IME 使用真实 Ghostty。每种证据只证明自身覆盖的内容，不能用快照替代交互、用假时钟证明网络一定可恢复。

## 3. 关键组合场景

优先走三条完整用户路径：F01/F02/F03 的工具现场→恢复→历史；F04/F05 的长工具→展开→输入→审批→返回→缩放；F06 的提交确认丢失→自动查询→切会话→晚到响应。其余边界下沉到便宜的测试层，不把所有排列组合做成慢端到端测试。
