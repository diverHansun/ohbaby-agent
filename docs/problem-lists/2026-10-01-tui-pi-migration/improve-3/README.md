# improve-3：工具输出、Markdown 与自动恢复

2026-10-03 开启。**设计与实施计划，尚未实施、尚未验收。** 用户明确要求在 improve-1/2 尚未形成 05 前继续规划本轮；这是提前规划被切出的 D，并加入已确认的自动恢复调整，不代表前两轮已经交付。

本轮让工具结果直接出现在终端时间线中：读和搜索保持简短，文件修改显示真实 diff，命令显示输出；Ctrl+O 展开工具详情，再按恢复正常紧凑 TUI；主动切换允许 Pi 式必要的一次清屏重印，随后普通刷新保持稳定。保留 React/Ink，按需接入官方 pi-tui 的 Markdown 和文本宽度能力。去除 Ctrl+R 手动恢复，由系统自动尝试。
