# 讨论记录与已确认要点

> 2026-10-20 开始讨论，2026-10-21 补充定稿。本文记录最终确认的行为，替代早期“创建后不能换目录、只能复制到项目”的结论。实施方案见 [02](02-optimization-plan-and-change-scope.md)。

## 1. 背景与推进顺序

ohbaby Web 目前必须先打开项目目录才能对话。用户希望直接开始聊天，项目由自己决定是否选择；已有会话也能像 Codex 一样通过右键菜单调整项目归属。TUI 在启动目录下工作，现有使用方式保留。

2026-10-21 再次审核后，用户确认按功能分两批实施：第一批工作区绑定优化，第二批设置；每批带上必要的后端、SDK 和 Web 页面。Web 参考 pi-agent-desktop 等产品的侧边栏和输入框结构，本轮先确定功能与布局，详细设计另做。

## 2. 新会话、项目归属与工作目录

| 操作或概念 | 已确认行为 |
|---|---|
| 点“新会话” | 打开空白草稿，默认不选项目，不立即创建服务端会话 |
| 编辑草稿 | 可以输入内容、选择或更换项目；换项目保留已输入文字 |
| 第一次发送 | 正式创建会话；所选项目决定初始工作目录 |
| 没选项目就发送 | 使用 `<OHBABY_HOME>/workspace/default`；未自定义 home 时是 `~/.ohbaby/workspace/default` |
| 默认工作区的粒度 | 第一版所有新建的无项目会话共用这个真实目录，沿用一个目录一个实例 |
| 无项目会话的能力 | 普通 agent 会话，工具和权限规则与项目会话一致，没有单独的 Chat 模式 |
| 已有会话换项目 | 右键会话 → Project → 选择已有项目；保留原会话 ID 和完整历史 |
| 运行时换项目 | 允许操作。归属立即改变，当前轮继续用原目录，下一轮开始用目标项目目录，即讨论中的方案 A |
| 换项目时的排队消息 | 该会话还没开始的排队消息随会话一起改到目标目录 |
| 换项目时的目标（goal） | 2026-10-21 确认：原目录不再续跑，目标保留但进入暂停；用户在目标目录继续后照常运行。不为此增加跨实例的目标交接机制 |
| 请求打到旧目录 | 每轮开始前以数据库为准（有待生效目录时以它为准，否则为执行目录）；旧目录的实例收到已移走会话的请求时，返回明确错误和目标目录，客户端换目录重发 |
| 换项目后的权限 | 不迁移。目标目录使用自己的权限状态，原目录里的放行规则和已批准的外部路径不带过去，需要授权的操作在目标目录重新询问 |
| 新建会话的归属 | 在共用的创建入口统一写入：默认工作区为空，其它为该目录；子代理继承父会话；归属直接存目录路径 |
| 移出当前项目 | 菜单提供“从当前项目移出”；归属变为空，保留实际工作目录，取消尚未生效的目录切换，不自动搬到默认目录 |
| 运行时移出 | 同样允许，不打断当前回复，不改变工作目录 |
| 项目名称 | 默认显示项目根目录名；同名目录仍是不同项目，身份依据目录而非显示名称 |

“无项目”表示没有侧边栏项目归属。新建无项目会话使用默认目录，但从项目移出的会话仍可使用原目录，两者不能混为一谈。

首次发送后，工作目录不再由草稿选择器随意修改；后续通过会话的 Project 菜单按上述规则变更。

## 3. 全局会话搜索

| 决策项 | 已确认规则 |
|---|---|
| 范围 | 跨项目与无项目，覆盖全部未归档的历史根会话；不局限于最近 100 或 500 条 |
| 搜索内容 | 标题，以及用户、助手的可见正文；不搜索工具调用、工具结果、思考过程或内部提示词 |
| 分词 | 按空白拆开关键词，忽略首尾和连续空白 |
| 匹配 | 所有关键词必须在同一个标题，或同一条消息内全部出现，顺序不限 |
| 字面规则 | 每个关键词按连续子串匹配，英文不区分大小写，标点按普通字符处理；不做正则或模糊匹配 |
| 去重 | 一个会话只显示一次，即使多条消息命中 |
| 排序 | 标题命中的会话在前，只有正文命中的在后；每组按会话最近更新时间倒序 |

例如搜索“登录 报错”，“报错发生在登录时”可以命中；若“登录”只在一条消息、“报错”只在另一条消息，就不命中。标题里只有“登录”、正文里只有“报错”也不能拼成一次命中。

## 4. 设置第一版

| 页面 | 范围 |
|---|---|
| 通用 | 前端偏好，保存在浏览器本地 |
| 模型 | 展示和编辑当前一套连接配置，复用已有配置与保存入口 |
| MCP | 只读展示服务器状态、失败原因、已加载工具数量和工具列表 |
| Skills | 只读展示当前工作目录下生效的 Skills |
| Agents | 只读展示当前工作目录下生效的 Agents |
| 联网搜索 | 展示配置状态，复用已有搜索 key 保存入口 |
| 关于/诊断 | 版本、目录与诊断信息 |

模型设置先做方案 A；后续再增加方案 B，即保存多套 LLM provider 配置并切换。这里的 A/B 与默认工作区的方案编号无关。

项目级配置第一版只读。模型和搜索凭据复用已有写入能力，不另建一套设置存储。接口不返回凭据原文。

## 5. 本轮边界

- 沿用 `InstanceStore` 与 `x-ohbaby-directory`，保持现有 TUI 使用方式。
- 保留侧栏已有的置顶、排序等能力，替换单项目视图。
- 不做每个无项目会话一个子目录，不做多 provider 配置保存。
- 不做 MCP 配置在线编辑、增删或重连，不做项目配置在线编辑。
- 权限默认值持久化、hooks、快捷键、插件页不在本轮。
- 按 KISS 完成常见使用流程，不增加独立的后台任务迁移或调度机制。
- 本轮只维护议题文档，不写“关键改动清单”，不另起模块级 improve 文档。详细前端设计留到前端实施前。
