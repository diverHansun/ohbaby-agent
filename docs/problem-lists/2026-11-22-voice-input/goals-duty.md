# 语音输入：目标与职责

"语音输入"指一个横跨三层的功能模块：Web 里的录音和界面、daemon 里的中转和识别服务对接、ohbaby-agent 里的语音配置读写。本文把它当作一个模块来定边界。

## 1. Design Goals

| 目标 | 说明 | 怎么算达到 |
|---|---|---|
| G1 说完就能用 | 停止录音到文字出现在输入框，等待尽量短 | 云端：10 秒以内的语音，停止后 2 秒内出字（网络正常时） |
| G2 不打断编辑 | 录音期间输入框照常能打字、能改控件，录音只是"多一条输入来源" | 录音中可以输入、移动光标、切换模型 |
| G3 密钥不出 daemon | 百炼 API key 只存在 daemon 所在机器，浏览器拿不到 | 浏览器的请求和页面里都看不到 key |
| G4 换识别引擎不动界面 | 云端和以后的本地识别对浏览器是同一套协议 | App 阶段接入本地识别时，Web 前端不改代码 |
| G5 出错说得清 | 没权限、没麦克风、没配置、网络断、识别失败、没听清，各有明确提示，不吞掉错误 | 前端 04 的错误表现逐条可复现 |

几个目标之间的取舍：G1 要求边说边传（录音时音频就在路上），所以选 WebSocket 而不是录完再上传；G3 要求经过 daemon 中转，多一跳，但 daemon 在本机，延迟可以忽略。

## 2. Duties

| 职责 | 归哪一层 |
|---|---|
| D1 采集麦克风音频，转成 16kHz 单声道 16 位 PCM，每 100ms 一块 | Web |
| D2 录音时根据音量画波形 | Web |
| D3 管理一次录音的状态：开始、录音、识别中、完成、取消、出错 | Web |
| D4 把识别结果插到输入框光标处（没有光标就接在末尾） | Web |
| D5 Audio 设置分区：读写语音配置，API key 只写不读 | Web |
| D6 接收浏览器的音频流，鉴权，转发给识别引擎，把最终文字回传 | daemon |
| D7 对接百炼实时识别：建连、`run-task`、发音频、`finish-task`、收结果、处理失败 | daemon |
| D8 定义识别引擎的接口，让云端和本地两种实现可以替换 | daemon |
| D9 读写 `~/.ohbaby/audio.json`，把 API key 写进 `~/.ohbaby/.env`，并和模型、搜索的密钥变量名互不冲突 | ohbaby-agent（配置） |
| D10 提供语音设置的 HTTP 接口和 SDK 契约类型 | daemon + ohbaby-sdk |

## 3. Non-Duties

| 不负责 | 说明 |
|---|---|
| 显示中间识别结果 | 00 已确认不做 |
| 自动发送、语音指令 | 识别结果只是文字，发不发由用户决定 |
| 本地识别的实现、模型下载 | App 阶段的工作。本模块只留好 D8 的接口和 00 §4 的存放位置 |
| 选择麦克风设备 | 用浏览器默认设备 |
| 热词、上下文增强 | 百炼支持（`vocabulary`、`input.context`），但现在没有需求 |
| 保存录音 | 音频只在内存里转发，识别完就丢，不落盘 |
| TUI | 不做 |
| 侧边对话、编辑历史消息等其他输入框 | 只给主输入框加麦克风 |

## 4. 与关联模块的边界

| 关联模块 | 边界 |
|---|---|
| 终端（`packages/ohbaby-server/src/protocols/web/routes/terminals.ts`） | 共用 daemon 的 WebSocket 升级入口和鉴权方式，各管各的路径 |
| 搜索设置（`packages/ohbaby-agent/src/config/tools/search/`） | 语音配置照它的写法，共用 `.env` 和密钥冲突检查 |
| 输入框（`apps/ohbaby-web/src/ui/composer/`） | 语音只往草稿里插文字，不改草稿保存、发送、插话的规则 |
| [模型与思考强度合并](../2026-11-22-composer-model-effort/README.md) | 先腾出底部一行的宽度，本模块再放麦克风和波形 |
