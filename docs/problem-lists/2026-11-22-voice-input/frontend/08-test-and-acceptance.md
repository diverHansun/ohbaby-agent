# 前端 08：测试与验收

> 模块级的自动化测试（配置、daemon、协议、PCM 转换）见 [test](../test.md)。本文从用户操作出发，写浏览器里怎么验收。

## 1. 验收标准

### V-1 第一次配置

1. 打开设置，导航里有"Audio"，在"Web search"下面。
2. 填 Base URL 和 API key，保存。保存后 API key 显示"Configured"，保存按钮变回不可用。
3. 刷新页面再打开，Base URL 还在，key 仍是"Configured"，页面上看不到 key 本身。
4. 在另一个标签页里打开设置，Audio 分区显示的是新值。

### V-2 说一段话

1. 在输入框里先打几个字，把光标放在中间。
2. 点麦克风，第一次会弹浏览器的授权框，允许。
3. 说一句中文。波形随说话起伏，麦克风变成深色实心方块。
4. 点这个方块。按钮转圈，空白处显示 `Transcribing…`，2 秒内（10 秒以内的话，网络正常时）文字插到光标处。
5. 按 Ctrl/Cmd+Z，刚插入的文字被撤销。
6. 消息没有自动发送。

### V-3 录音时照常编辑

1. 开始录音后，在输入框里继续打字、移动光标、换模型。都正常。
2. 停止后，文字插在停止那一刻的光标处，而不是开始录音时的光标处。

### V-4 取消

1. 录音中按 Esc：波形消失，按钮回到麦克风，输入框没变，浏览器的录音标记熄灭。
2. 识别中按 Esc：同样回到空闲，识别结果不会再插进来。
3. 运行中（显示"停止运行"按钮）开始录音，按一次 Esc：只取消录音，运行不停止。

### V-5 出错

逐条复现 [04 §5](04-interaction-and-states.md) 的错误表，每条的提示文案和之后的状态都对得上，输入框里已有的文字不变。

## 2. 测试分层

| 层 | 覆盖 |
|---|---|
| 单测（Vitest + jsdom） | `useVoiceInput` 状态机、`VoiceButton` 各状态的图标和标签、插入规则、`audio-form.ts`、`AudioSection` 的保存。麦克风、`AudioContext`、WebSocket 都用假的 |
| 集成（Vitest） | `Composer` 里录音和发送按钮、Esc 优先级、切会话取消的配合 |
| 浏览器走查 | §1 的验收标准、§4 的视觉清单。要真实麦克风和真实百炼 key，由用户配合 |

## 3. 关键场景

| ID | 场景 | 层 | 验证点 | 对应 |
|---|---|---|---|---|
| F-1 | 未配置时点麦克风 | 单测 | 打开 Audio 分区，不申请麦克风 | 04 §2 |
| F-2 | 还没读到配置时点麦克风，daemon 回 `not_configured` | 单测 | 停麦克风，提示，打开 Audio 分区 | 04 §2 |
| F-3 | 状态转换 | 单测 | 04 §1 状态图的每一条边 | 04 §1 |
| F-4 | 建连慢 | 单测 | `started` 之前录的音频按顺序在 `started` 之后发出，一块不少 | 04 §1 |
| F-5 | 在 `started` 之前点停止 | 单测 | 等 `started`，发完队列，再发 `finish` | 04 §1 |
| F-6 | 发送按钮和回车 | 集成 | `recording`、`transcribing` 期间发送按钮不可用、回车不发送；识别完成后恢复 | 04 §3 |
| F-7 | Esc 优先级 | 集成 | 菜单或设置对话框打开时 Esc 只关它们，录音继续；录音时 Esc 取消录音且不计入连按两次停止运行；焦点在麦克风按钮上时 Esc 也能取消 | 04 §3 |
| F-8 | 切会话 | 集成 | 录音被取消，麦克风释放，新会话的输入框不受影响 | 04 §3 |
| F-9 | 插入位置和空格 | 单测 | 光标在中间、有选区、没点过输入框；中英文边界补空格 | 04 §4 |
| F-10 | 每种错误 | 单测 | 04 §5 每一行的文案和之后的状态 | 04 §5 |
| F-11 | 不安全的地址 | 单测 | `isSecureContext = false` 时按钮不可用，标签正确 | 04 §5 |
| F-12 | 5 分钟上限 | 单测（假计时器） | 到时自动停止并识别，出现提示 | 04 §3 |
| F-13 | 清理 | 单测 | 所有结束路径后麦克风轨道停止、`AudioContext` 关闭、连接关闭；取消后再到达的 `completed` 被忽略，不插入文字 | 04 §1 |
| F-14 | Audio 设置表单 | 单测 | 只提交改过的字段；Base URL 不合法时标红；语言提示超过 4 个时标红；key 留空表示不改 | 05 §3.5 |
