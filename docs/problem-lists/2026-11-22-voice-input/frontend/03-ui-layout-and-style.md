# 前端 03：布局与样式（简写）

> 本议题只在已有界面上加几个元素，不新建页面，所以 03 按精简模式简写：沿用 `docs/ohbaby-web/redesign-2026-10/` 已定的视觉体系，只写新元素的位置、线框、文案和验收口径。

## 1. 设计原则

| 原则 | 落到本议题 |
|---|---|
| 沿用现有体系 | 颜色、字号、圆角、图标都用现有的 token 和 lucide 图标，不引入新的视觉语言 |
| 不用胶囊和卡片 | 麦克风是普通图标按钮，波形是几根细竖条，提示是一行次要色文字。不给波形加底色块、不做胶囊 |
| 录音状态一眼可见 | 录音时有两处变化：底部一行出现会动的波形，麦克风按钮变成实心停止方块。不用弹窗或遮罩，也不用红色（redesign-2026-10 D32：红色只留给错误） |
| 不挡编辑 | 录音期间输入框和底部控件照常显示、照常可用 |

## 2. 视觉方向与来源

| 来源 | 借鉴什么 |
|---|---|
| Claude App 的语音输入 | 波形放在输入卡片底部一行的空白处，在卡片内部 |
| Codex 的语音输入 | 录音时只显示波形，不显示中间文字 |
| ohbaby 现有输入框（redesign-2026-10 D22、D29） | 底部一行的结构：左边权限，右边模型、发送；手机宽度下的"更多"菜单 |

## 3. Design Tokens

不新增 token，只用已有的语义 token：

| 元素 | 用哪个语义 |
|---|---|
| 麦克风图标（空闲） | 和底部一行其他图标按钮相同的次要文字色，悬停时和它们一样变深 |
| 停止方块（录音中） | 主文字色（深色），没有底色 |
| 波形竖条 | 次要文字色（`--text-dim` 一档）；声音大时不换颜色，只变高 |
| "Transcribing…" 文字 | 次要文字色，和按钮里的强度文字同一档 |

## 4. 页面布局与关键线框

### 4.1 输入框底部一行（桌面）

前提：[模型与思考强度合并](../../2026-11-22-composer-model-effort/README.md) 已经把原来的思考强度下拉框并进模型按钮。

空闲：

```
┌──────────────────────────────────────────────────────────────────┐
│ 输入框文字……                                                      │
│                                                                  │
│ [Auto ▾]                                  [qwen3-max  High ▾] 🎙 (↑)│
└──────────────────────────────────────────────────────────────────┘
```

录音中：

```
┌──────────────────────────────────────────────────────────────────┐
│ 输入框文字……（照常可以编辑）                                       │
│                                                                  │
│ [Auto ▾]           ▁▂▅▃▇▅▂▁▃▅▂▁           [qwen3-max  High ▾] ■ (↑)│
└──────────────────────────────────────────────────────────────────┘
```

识别中：

```
│ [Auto ▾]                   Transcribing…  [qwen3-max  High ▾] ◌ (↑)│
```

| 元素 | 位置和尺寸 |
|---|---|
| 麦克风按钮 🎙 | 紧挨在发送按钮左边。和底部一行其他图标按钮同样大小，没有底色 |
| 停止按钮 ■ | 就是麦克风按钮本身换了图标：深色实心小方块，没有底色。右边的"停止运行"按钮是黑色圆底上的白色方块，两者靠有没有圆底区分，不会混淆 |
| 识别中 ◌ | 同一个按钮换成转圈图标，不能点 |
| 波形 | 放在底部一行的空白处（现有的 `ohb-composer-bar-spacer`），靠右，紧挨模型按钮左边。宽 120–160px，空间不够时缩，最小约 48px |
| "Transcribing…" | 和波形同一个位置，波形消失后显示 |
| 发送按钮 (↑) | 录音和识别期间变成不可用的样子（**待用户确认**，见 04 §3） |

波形的样子：一排等宽细竖条，从右往左滚动，最新的音量在最右边。每秒至少更新 20 次。没有声音时是一排贴底的短条，不是空白，让用户知道录音在进行。

### 4.2 设置 › Audio 分区

导航里加在"Web search"后面，名字叫"Audio"。版式和 Web search 分区一致（`ui/settings/SearchSection.tsx`）：

```
Audio
Voice input by Alibaba Cloud Model Studio · Get an API key ↗
Recordings are sent to Alibaba Cloud for transcription and are not stored.

Base URL              [https://<workspace>.cn-beijing.maas.aliyuncs.com    ]
                      Copy it from the Model Studio console.
API key               [ Configured · Replace ]
Remove filler words   [✓] Drops "um", "uh" and similar words.

▸ More options
    Model             [qwen-audio-3.1-asr-flash-message                    ]
    Language hints    [zh, en                                              ]
                      Up to 4, comma-separated. Leave empty to auto-detect.
    Key variable      [OHBABY_AUDIO_API_KEY                                ]

                                                                  [ Save ]
```

| 项 | 说明 |
|---|---|
| 第二行说明 | 告诉用户录音会发到阿里云，并且不保存（[non-functional §2.4](../non-functional.md)） |
| "Get an API key" | 链到百炼控制台的 API key 页面。国内版和国际版地址不同，实施时确认 |
| 字段顺序 | 必填的放上面（Base URL、API key），开关其次，不常改的进"More options" |
| 保存 | 和 Web search 一样：只发改过的字段，保存成功后按钮回到不可用 |

服务商只有百炼一家，所以不放服务商下拉框，写在第二行说明里。App 阶段加本地识别时再加。

## 5. 响应式策略

| 宽度 | 底部一行 |
|---|---|
| ≥ 640px | 如 §4.1 |
| < 640px | 现有的"更多"菜单 + 模型按钮 + 麦克风 + 发送。录音期间模型按钮隐藏，给波形腾位置（**待用户确认**），停止后恢复。波形最小约 48px |

375px 宽度下底部一行不能换行。

## 6. 内容与文案

界面文字用英文，和现有界面一致。

| 场景 | 文案 |
|---|---|
| 麦克风按钮（可用） | 悬停和读屏：`Voice input` |
| 麦克风按钮（未配置） | `Set up voice input` |
| 麦克风按钮（不安全的地址） | `Voice input needs localhost or HTTPS`，按钮不可用 |
| 停止按钮 | `Stop recording (Esc to cancel)` |
| 识别中 | 按钮 `Transcribing…`；空白处文字 `Transcribing…` |
| 录音和识别期间的发送按钮 | `Finish voice input first` |

出错提示的文案见 [04 §5](04-interaction-and-states.md)。文案规则：说清楚发生了什么，能给出下一步就给（比如"去设置里检查 key"），不出现技术词（不写 WebSocket、4401）。

## 7. 视觉验收口径

| 项 | 怎么算通过 |
|---|---|
| 位置 | 截图里波形在卡片内部、底部一行，没有新增一行，没有遮住输入框文字 |
| 不像胶囊 | 麦克风、停止按钮、波形都没有底色块和胶囊边框 |
| 停止按钮可区分 | 和"停止运行"按钮并排出现时（运行中录音），一眼能分出两个按钮 |
| 波形在动 | 说话时竖条起伏明显，不说话时是一排短条 |
| 窄屏 | 375px 下底部一行不换行，波形可见 |
| 深浅色 | 两种主题下波形和停止方块都清楚 |
| 没有红色 | 录音相关的元素里没有红色（D32），红色只出现在出错提示里 |
| 设置页 | 和 Web search 分区对比，版式一致 |

## 8. 实现约束摘要

| 类别 | 内容 |
|---|---|
| 必须遵守 | 波形在卡片内部底部一行；录音时底部控件不隐藏（手机宽度下的模型按钮除外，待确认）；停止按钮和"停止运行"按钮有明显区别；录音元素不用红色（D32）；不用胶囊、卡片样式；只用已有 token |
| 初值可调 | 波形宽度 120–160px、竖条粗细和间距、滚动速度 |
| 自由发挥 | 竖条的圆角、高度变化的缓动、转圈图标的样式 |
