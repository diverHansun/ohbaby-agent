# 语音输入

本议题于 2026-11-22 开启，给 ohbaby Web 输入框加语音输入：点麦克风开始录音，录音时输入框里显示波形，停止后把识别出的文字插进输入框。识别走阿里云百炼的实时语音识别（`qwen-audio-3.1-asr-flash-message`，WebSocket 边说边传）；本地识别（Qwen3-ASR-0.6B int8）等 App 端做完再接入。只做 Web，不做 TUI。

姊妹议题 [输入框模型与思考强度合并](../2026-11-22-composer-model-effort/README.md) 先把两个控件合成一个，给麦克风和波形腾出位置。

## 范围

| 本轮做 | 本轮不做 |
|---|---|
| 设置里新增 Audio 分区：填百炼的 Base URL、API key、模型和润色开关 | 本地识别的实现（App 阶段做，本轮只定好接口边界和存放位置） |
| 输入框麦克风按钮、录音波形、停止后插入文字、Esc 取消 | 边说边显示文字（中间结果） |
| daemon 中转：浏览器 → daemon → 百炼，API key 只留在 daemon | 自动发送、语音指令、唤醒词 |
| 新的 `~/.ohbaby/audio.json` 和对应的设置接口 | TUI、麦克风设备选择、热词、上下文增强 |

## 待用户确认

下列几项是本文档给出的建议，讨论时还没逐条确认过，审查文档时请重点看：

| 项 | 建议 | 位置 |
|---|---|---|
| 未配置时点麦克风 | 直接打开设置的 Audio 分区 | 前端 04 §2 |
| 录音和识别期间能不能发送 | 发送按钮和回车发送暂时禁用，识别完成后恢复 | 前端 04 §3 |
| 单次录音上限 | 5 分钟，到时自动停止，按正常停止处理 | non-functional §2 |
| 润色（去掉"嗯、啊"等口头语） | 默认打开，设置里可以关 | data-model §3 |
| 手机上录音时模型按钮 | 录音期间隐藏，给波形腾位置。和 00 §2"底部控件照常显示"有出入，只限 640px 以下 | 前端 03 §5 |
