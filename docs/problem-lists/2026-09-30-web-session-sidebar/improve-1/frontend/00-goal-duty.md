# 目标与职责

## 1. 产品目标

让长期 Web 用户更容易阅读、定位和整理当前项目会话，减少常驻装饰与操作按钮。

## 2. 用户角色

单一权限身份的本地工具用户。初次使用看空列表及 New session，日常用户阅读/置顶/归档。

## 3. 核心任务

T-01 识别并打开会话；T-02 置顶及取消置顶；T-03 通过菜单归档。

## 4. 职责边界

前端负责显示、客户端 pin、菜单和动效；服务端继续负责会话索引/归档事实。pin 不影响 active session、updatedAt、TUI。

## 5. Non-goals

见 [确认边界](../00-discussion.md)：本轮不做 Rename、恢复、设置、拖拽、移动端专项、跨设备同步和额外分组标题。
