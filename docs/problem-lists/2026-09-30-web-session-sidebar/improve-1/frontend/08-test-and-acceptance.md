# 前端验收计划

## 1. 用例标准

UC-01：没有圆点/footer/Select tooltip；选中和 New session 仍有效；空态可继续创建。
UC-02：两入口同菜单，Pin 排最前；active session/scrollTop 保持；刷新恢复，项目隔离。
UC-03：实心 pin 和菜单 Unpin 同效；返回普通顺序；按钮不误选聊天；焦点不跳屏。
UC-04：确认/取消/失败/成功；成功才清 pin；跨项目进行中的归档不串 scope。

## 2. 分层

单元验证存储与排序；jsdom 验证操作及焦点；真实浏览器验证布局、动画、滚动、菜单边缘和截图。对应 [A1–A9](../04-test-and-acceptance.md)，不以 jsdom 尺寸模拟代替视觉证据。

## 3. 关键场景

短/长标题、两个项目、30 条列表滚动、菜单在右下角、键盘、减少动态效果、存储不可用、归档延迟后切项目。临时 harness 使用 [06](06-data-api-and-state.md) 数据。

## 4. 视觉清单

桌面 1280×800，补窄窗口 760×700；默认/hover/置顶/菜单各截图。检查标题对齐、按钮遮挡、卡片紧凑程度、菜单不裁切、实心 pin 位置。重排采集中间帧；长标题比较 600ms 前后位移及末尾停留。无 blank/error overlay/相关 console error。
结果写 09，未验证项明确列出。参考图保留在用户附件；不要求把大尺寸截图外观逐像素复制。

补充：检查静止标题直接裁切、没有省略号，裁切/滚动切换无跳变；ContextMenu/Shift+F10；滚动后置顶移出可见区仍保持 scrollTop；归档行移除后的焦点落点。
