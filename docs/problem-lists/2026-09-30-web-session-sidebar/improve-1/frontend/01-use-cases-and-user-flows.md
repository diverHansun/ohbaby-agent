# 用例与流程

## 页面与权限

只有已有项目会话侧栏，无新路由。所有本地用户权限相同；沿用 composer.disabled 的连接禁用约束，无新增角色体系。

| 用例 | 任务 | 主流程 | 异常分支 |
|---|---|---|---|
| UC-01 阅读 | T-01 | 打开侧栏 → 读标题 → 选择会话 | 空列表保留 New session；同步中沿用现有禁用状态 |
| UC-02 整理 | T-02 | hover … / 右键 → Pin → 行移动到置顶顶部 | 保存失败保留当前页结果并提示；不改变当前聊天/滚动 |
| UC-03 取消 | T-02 | 点左侧实心 pin 或菜单 Unpin → 普通排序 | 同 UC-02 保存异常 |
| UC-04 归档 | T-03 | 菜单 Archive → 现有确认 → 后端归档成功 → 清 pin | 取消或失败不清 pin；错误走现有 ErrorBanner |

键盘 Tab 到 …，Enter 开菜单、箭头导航、Escape 关闭。右键不选择会话。菜单同一时刻只开一个，不生成遮罩。
