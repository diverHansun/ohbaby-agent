# 讨论记录与已确认要点

2026-09-30，来自当前对话的最终有效结论。用户原话摘录：

> 行内 hover 只显示「…」，空心 pin 放进菜单，已经置顶会话的"..."点击后/右键和弹出的小卡片显示Unpin。也可以直接点击实心的pin icon进行unpin操作。

> 在列表下方置顶一条会话时，留在当前滚动位置：位移动画只表现屏幕内能看到的那段。

## 目标与范围

- 标题改 Sessions；删除底部数量与分割线。
- 删除会话左侧圆点（包括其运行闪动）；置顶后在标题左侧显示唯一实心 pin，可直接 Unpin。图标槽保留以对齐标题，间隔适当。
- hover/键盘聚焦显示右侧 …，保持到离开；点击或右键/触控板双指点按打开同一菜单，仅 Pin/Unpin 与 Archive。
- 置顶保存在浏览器、按服务与当前项目路径隔离；后置顶排最前，不随消息更新变化。取消置顶回普通更新时间顺序。
- Pin/Unpin 不选择聊天、不改变阅读区；重排有克制的位移动画，不滚到顶部、不弹成功通知。
- 标题真正溢出才缓慢滚动；600ms 是开始前停留初值，不是按钮消失时间。到末尾停，移开复位；菜单/重排期间暂停。
- 归档是保存的 archived 状态，不是删除；本轮沿用确认框，归档成功才清理 pin，失败/取消保留。

## 本轮不做

后端/TUI pin、跨设备同步、拖拽排序、Rename、设置、归档列表/恢复、移动端专项交互、批量操作、装饰性提示。
