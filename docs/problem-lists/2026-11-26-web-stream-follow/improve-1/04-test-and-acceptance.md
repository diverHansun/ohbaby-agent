# 验收标准

1. 一条提问还放得下一屏时向上滚一次，随后依次追加工具行和多段正文。旧版停在开头；修复后在稳定帧测得消息区距底部至多 1 CSS 像素。
2. 跟随长回答时，分别测试点击普通正文、在底部继续向下滚。工具过程自动折叠后仍应跟随。再增加内容高度，或改变布局高度，确认视口仍在底部。布局造成的位移不能被当成用户主动回到底部的通知。
3. 长列表中真实上翻，记住屏首消息和位置。新消息到达后继续读原段落；再手动回到底部，后续输出应跟随。
4. 回归现有历史分页、阅读锚点和手动折叠测试。用编译 Web、隔离 daemon、真实 Chrome 和可控模型输出跑一次完整发送流程，确保正常入口也覆盖短页上滑、流式增长和结束折叠。验收记录注明哪些输入在组件测试、哪些在完整页面中验证。
