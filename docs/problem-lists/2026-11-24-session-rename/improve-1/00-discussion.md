# 0. 讨论与已确认要点

> 本文记录 2026-11-24 讨论后确认的结论，被否决的方案不再展开。

## 0.1 用户提出的问题

会话标题现在只能由系统自动生成，用户没法自己改。用户希望在侧边栏给主会话改名：打开会话菜单（点 `…` 或右键）选 Rename，标题变成可编辑的输入框，按回车完成。后端要补上对应的逻辑。

## 0.2 现状核实

- 标题存在会话表里。新会话叫 `New session`，第一条消息发出后先用消息内容生成临时标题，再让 LLM 异步生成正式标题。
- LLM 写标题前会核对标题还是不是它当初看到的那个，不一样就放弃。所以用户手动改过的名字不会被晚到的自动标题覆盖，这部分不用新写。
- 没有任何改标题的接口，SDK、server、Web 都没有。
- `sessionManager.update` 每次都会刷新 `updatedAt`，而侧边栏按 `updatedAt` 排序。直接复用它，改完名会话会跳到列表最上面。

## 0.3 已确认的决定

| 编号 | 决定 |
|---|---|
| C1 | 只做 Web，不做 TUI |
| C2 | 改名不改变会话在列表里的位置，也就是不刷新 `updatedAt` |
| C3 | 入口有两个：会话菜单（`…` 和右键是同一个菜单）里的 Rename，和双击标题 |
| C4 | 回车保存，Esc 取消，点到输入框外面（失焦）也保存 |

## 0.4 按默认处理（讨论中未提异议）

- 只有主会话能改名。子代理会话和 side chat 直接拒绝。
- 会话运行中、等待审批时也能改名，这和归档不同。
- 标题去掉首尾空白，连续空白（含换行）合成一个空格，最长 120 个字符。
- 清空或没改动时不发请求，直接恢复原名。
- 先在界面上显示新名字，请求失败再改回来，并弹一条错误提示。
- 改名后其他窗口、顶栏、搜索都跟着更新。
- 把空会话改成 `New session`、`Untitled session` 这类默认名，系统仍把它当默认名，发第一条消息后会自动起名。
- 手机宽度下单击会话会关掉侧边栏，双击用不了，改名走菜单。

## 0.5 明确不做

- 不做 TUI 的 `/rename`。后端接口做好后，以后加它成本很低，可以单开议题。
- 不在顶栏标题上提供改名入口。
- 不提供"让 LLM 重新生成标题"。
