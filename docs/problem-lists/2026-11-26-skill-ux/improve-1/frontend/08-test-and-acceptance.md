# 08 测试与验收

> 用例编号见 [01](01-use-cases-and-user-flows.md)，状态见 [04](04-interaction-and-states.md)，Mock 场景见 [06](06-data-api-and-state.md) 第 5 节，视觉口径见 [03](03-ui-layout-and-style.md) 第 7 节。后端和 TUI 的测试在 [../04](../04-test-and-acceptance.md)，这里只写 Web。代码路径省略前缀 `apps/ohbaby-web/src/`。

## 1. 验收标准

### UC-SKILL-01 用命令面板选 skill 并发送（T-01、T-02）

- [ ] 敲 `/`，面板里能看到 skill；选中 `code-review`（回车、Tab、点击各试一次），输入框里只剩技能标记，刚才敲的 `/xxx` 没了，**消息没有发出去**。
- [ ] 选中 `/compact` 这类命令，行为和改动前一样。
- [ ] 只有标记、不写原话时，Send 可用，回车能发出去；气泡里只有标记。
- [ ] 写上原话再发，气泡开头是标记，后面接原话；气泡里没有 SKILL.md 的任何文字。
- [ ] 后端收到的文字是 `/code-review 帮我看看这个 PR`；只有标记时是 `/code-review`。
- [ ] 原话写多行、带缩进，第二行起的换行和缩进在后端收到的文字和气泡里都一字不差（第一行首尾空白会被去掉）。
- [ ] 有标记时，先发一次失败，再换一个标记、原话不动重发，后端收到的是新 skill，不是第一次的回执。
- [ ] 点发送后标记和原话立即清空，成功后保持清空。
- [ ] 发送失败（草稿里的 skill 已不在命令目录，或用 `&delay=` 加断网）时显示现有的发送错误，标记和原话一起写回输入框。
- [ ] 发送中连按回车，只发出一条。
- [ ] 运行中发送（排队），排队列表里显示纯文字 `/code-review 原话`。
- [ ] 运行中输入框里只有一个标记时，按钮是 Send，不是 Stop。
- [ ] 复制这条消息，得到 `/code-review 帮我看看这个 PR`。
- [ ] 排队期间 skill 被删后发出的消息，气泡是普通文字 `/code-review 原话`，没有魔杖，也没有失败行。
- [ ] 发送后正式消息到达前，占位行显示纯文字 `/code-review 原话`，随后变成带标记的气泡。
- [ ] 原话很长、输入框出现滚动条时，往下滚，标记跟着第一行一起滚走；滚回顶部，标记回来，和文字不错位。

### UC-SKILL-02 从 /skills 弹窗插入

- [ ] 点 Insert 后弹窗关闭，输入框只剩标记，原有文字被替换，焦点在输入框。

### UC-SKILL-03 整体删除技能标记

- [ ] 光标在原话最前面、没选中文字，按一次退格，标记消失，原话不变，光标在最前面。
- [ ] 选中一段原话再退格，只删选中的文字，标记还在。
- [ ] 全选后删除，原话清空，标记还在。
- [ ] 输入法组字中按退格，标记不动。
- [ ] 删掉标记后发送，按普通消息发出，气泡里没有标记。

### UC-SKILL-04 草稿恢复

- [ ] 有标记加原话时刷新页面，恢复后还是标记加原话。
- [ ] 只有标记、没有原话时刷新，标记也能恢复。
- [ ] 手动往 `sessionStorage` 写一份没有 `skill` 字段的旧草稿，恢复成纯文字。

### UC-MSG-01 展开和收起长用户消息（T-03）

- [ ] 超过约 12 行的用户消息只露出约 8 行，截断处有 `…`，最后一行是 `Show more` 加向下箭头。
- [ ] 不到阈值的消息没有开关。
- [ ] 点 `Show more` 展开全文，变成 `Show less`；再点回到收起。点正文不会展开。
- [ ] 开关 hover 前后没有变化，切换没有动画。
- [ ] 带标记的长消息，标记在第一行，收起时也在。
- [ ] 用搜索跳到一条被收起的消息，它自动展开。
- [ ] 把窗口拉宽到不足阈值，开关消失；拉窄到超过阈值，出现开关。
- [ ] 刷新页面后回到收起。
- [ ] 旁聊里的长用户消息同样会折叠。
- [ ] 开关能用 Tab 选中，回车和空格都能切换，`aria-expanded` 跟着变。

### UC-MSG-02 编辑带 skill 的消息并重发（T-04）

- [ ] 点编辑，编辑框开头是标记，后面是原话，没有 SKILL.md 正文。
- [ ] 改原话后发送，历史截断，新消息带着同一个标记。
- [ ] 在编辑框里敲 `/`，面板只列 skill；选中后替换标记。
- [ ] 面板开着时按 Esc 只关面板；再按 Esc 才取消编辑。面板开着时按回车只选 skill，不发送。
- [ ] 删掉标记再发送，按普通消息发出。
- [ ] 只有标记没有原话，Send 可用。
- [ ] `&skillError=rewind` 时，提示行原样显示后端的错误文字，前面没有 `Something went wrong:`；编辑框不关，历史、运行状态和排队区都不变。
- [ ] 提交被拒（截断已经发生）时，主输入框里是这条消息的标记，后面是原话，原草稿接在后面，中间空一行。
- [ ] 升级前的旧 slash 消息点编辑，编辑框里是纯文字，没有标记。

### 用户气泡原样显示（00 F5）

- [ ] 含 `**加粗**`、`# 标题`、`- 列表`、反引号代码的用户消息，气泡里显示的就是这些符号，没有被渲染。
- [ ] 换行、空行、行首空格都保留。
- [ ] 带超长网址或长串无空格字符的消息，在 390 宽度下自动折行，不撑出横向滚动条。
- [ ] 网址是普通文字，不能点（已知退化）。
- [ ] 旁聊引用选中文字发出的消息，气泡里能看到开头的 `> `。
- [ ] 子代理页面的"From parent"提示仍按 markdown 渲染。
- [ ] 复制得到的文字和气泡里看到的一致。
- [ ] 助手回复照常按 markdown 渲染，没有受影响。

### 发送和停止按钮颜色（00 F4）

- [ ] 主输入框的 Send、Stop，编辑框的 Send，旁聊页的 Send、Stop 都是蓝色，hover 变深一点，禁用时仍是灰色。
- [ ] 编辑框的 Send 默认比主输入框的 Send 深一档（`--signal-hover`），hover 再深一档；白字对比度 ≥4.5:1。
- [ ] Stop 中间的方块是实心白色，和按钮里的图标同色。
- [ ] 审批卡片的 Allow、弹窗主按钮仍是黑色。
- [ ] 技能标记的蓝（`--skill-ink`）比按钮的蓝深，两者分开调。

## 2. 测试分层

按仓库现有规则：测试文件和源码放一起，命名 `*.unit.test.ts(x)` / `*.integration.test.ts(x)`，用 Vitest 加 Testing Library，跑 `npm test`。

| 层 | 覆盖 | 不覆盖 |
|---|---|---|
| 单元测试 | `splitSkillText`（含 `/name` 后接换行）、`composeSkillText`（多行原话不被改动）、`shouldRemoveSkillToken` 的各种输入；`draft-storage` 新旧草稿读写 | 渲染 |
| 组件测试 | `SkillToken`、`SkillTokenField`、`CollapsibleUserText`（用固定高度模拟测量）、`UserMessageEditor` 的 Esc 和回车顺序；在现有 `Composer.unit.test.tsx`（失败时 `pendingSkill` 写回）、`MessageRow.unit.test.tsx`（用户文字不出 markdown 元素，fromParent 仍出）、`message-copy.unit.test.tsx`、`message-edit-fork.unit.test.tsx`（`onSend` 收到 `{ skill, text }`）里补用例 | 真实布局、截图 |
| 样式测试 | 现有 `styles.unit.test.ts`：发送和停止按钮（主输入框、旁聊）用 `--signal`，编辑框的 Send 用 `--signal-hover`，`.ohb-button-primary` 和 `.ohb-perm-allow` 仍用 `--accent`；`--skill-ink` 不引用 `--signal`；组件 CSS 里没有字面量颜色 | 实际颜色观感 |
| 浏览器走查（mock） | `vite dev` 加 06 的 mock 场景，走 04 的状态矩阵和第 4 节的视觉清单 | 真实后端 |
| 浏览器走查（真实后端） | 后端 Stage 1、2 合入后，用 `ohbaby-web` 启动配置跑一遍 UC-SKILL-01 和 UC-MSG-02 的主流程 | 全部组合 |

`CollapsibleUserText` 的高度判断在 jsdom 里量不出来，组件测试只测"给定高度时开关出不出现"，真实换行和窗口变化放在浏览器走查里看。
