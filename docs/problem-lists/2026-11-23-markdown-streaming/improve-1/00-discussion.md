# 0. 讨论与已确认要点

> 本文记录 2026-11-23 讨论后确认的结论，被否决的方案不再展开。

## 0.1 要解决的问题

模型输出时，页面显示 13px 等宽纯文本；输出结束后才变成排版好的 Markdown，整段内容会跳一下。

## 0.2 已确认的决定

| 编号 | 决定 |
|---|---|
| C1 | 输出过程中就用和最终结果相同的渲染和样式 |
| C2 | 已写完的内容块不再改动，每次只重新解析最后两块（deepseek-harness 的做法，下文简称 dsh） |
| C3 | 未闭合的代码块边写边显示成代码块，不等结束标记 |
| C4 | 临时补全结尾半截的 `**` 和行内代码反引号，只影响显示，不改原文 |
| C5 | 输出完成后用全文再渲染一次，跨块的引用式链接在这一步恢复 |
| C6 | 不写新解析器，不用 Worker |
| C7 | 不按帧合并更新。单次更新已经不到 1ms，而且自动滚动紧跟在更新之后，推迟反而会慢一拍 |

## 0.3 明确不做

- 不补全半截的链接、图片、斜体和表格行，它们写完后自然变成正确的样子。
- 不做逐字淡入动画。
- 不改思考内容和工具输出的显示方式。
