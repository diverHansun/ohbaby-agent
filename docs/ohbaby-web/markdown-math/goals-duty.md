## 1. Design Goals（设计目标）

1. **模型常用的公式写法都能显示。** 不要求模型换写法，也不改系统提示词。
2. **不误伤普通文字。** 价格、shell 变量、代码和模板字符串保持原样。
3. **输出过程中就能读。** 一个公式写完就显示，不等整条消息结束。
4. **不拖慢普通聊天。** 没有公式的会话不下载 KaTeX，渲染不造成可感知的卡顿。
5. **公式写错时不打扰阅读。** 用户看到原始 LaTeX，页面上不出现报错。
6. **模型输出不可信。** 公式不能运行脚本、请求外部资源或改变页面布局。
7. **和正文协调。** 字号接近中文正文，宽公式不撑破页面。

## 2. Duties（职责）

| 编号 | 职责 | 怎样算做到 |
|---|---|---|
| R1 | 识别五种写法 | `$...$`、`$$...$$`、`\(...\)`、`\[...\]`，以及语言为 `math` 或 `latex` 的代码块 |
| R2 | 不误判普通文本 | `$5 和 $10`、`$HOME/$USER`、`$(id -u):$(id -g)`、代码里的 `$x$` 都不当作公式 |
| R3 | 保护公式内容 | 公式里的 `_`、`*`、`\` 不被 Markdown 解释 |
| R4 | 写完一个就显示 | 闭合的公式在输出过程中显示；未闭合的继续显示原文 |
| R5 | 按需加载 | 第一次出现公式时才下载 KaTeX 和样式，字体按需加载 |
| R6 | 失败时保留源码 | 语法错误、不支持的命令、超长或加载失败时，显示原始 LaTeX |
| R7 | 能拿回源码 | 选中公式复制得到 `$...$` 或 `$$...$$`；公式代码块的 Copy 复制源码 |
| R8 | 隔离不可信内容 | 不生成链接和图片，不接受 HTML 扩展命令，模型手写的占位 HTML 不生效 |
| R9 | 处理排版和宽内容 | 行内公式字号为正文的 1.1 倍，宽公式只在自己的区域内滚动 |
| R10 | 在 React 更新中保持稳定 | 内容不变时不重复渲染；内容变化时重新渲染；组件卸载后不再写 DOM |

## 3. Non-Duties（非职责）

- **不处理其他位置的 Markdown。** 用户消息、命令结果、文件预览、思考内容和工具输出保持现状。文件预览以后想打开，只需要传一个开关。
- **不支持 MathJax 独有的能力。** `\require`、`multline` 和 TikZ 这类内容显示源码。
- **不做化学式扩展。** `\ce{H2O}` 暂时显示源码，需要时再加 KaTeX 的 mhchem 扩展。
- **不修复模型写错的 LaTeX，也不提示错误原因。**
- **不处理表格里未转义的竖线。** GFM 会先把 `$|x|$` 里的 `|` 当作分列符，模型需要写成 `\|` 或 `\mid`。
- **不做公式编号跳转、缩放和导出图片。**
- **不做深色模式。** 公式颜色继承文字颜色，以后加主题时不用改。
- **不做 TUI 渲染。**
