# 07 质量约束

> 本地单用户工具，由 daemon 同源伺服。现有约束见 [non-functional.md](../non-functional.md)，本文只写这次改版相关的部分。

## 1. 无障碍

目标：WCAG 2.2 AA 的主要条款，对齐 03 §3.3。

- 全部操作可以用键盘完成：侧栏导航、菜单、搜索、审批、设置。快捷键见 04 §3。
- 焦点可见：统一 2px `--accent` outline，只在键盘操作时显示（`:focus-visible`）。
- 语义元素：可点击的都是 `<button>` 或 `<a>`；侧栏会话树用列表结构；菜单用 `role="menu"`。
- 只有图标的按钮都有可读名称（`aria-label`）。会话行的运行中、等待审批有文字标签。
- 对比度：`--text`、`--text-muted`、`--text-dim` 在 `--bg`、`--bg-panel` 和 `--bg-glass`（按最不利的背后内容）上都 ≥ 4.5:1。错误和警告文字用 `--danger-ink`、`--warning-ink`，不用圆点色（03 §3.1）。实现时如果调了色值，要重新核对。
- 点击区域：桌面 ≥ 22px（侧栏行内小按钮），其他 ≥ 28px；手机 ≥ 44px。
- `prefers-reduced-motion` 下关闭转圈以外的动画。

## 2. 性能

本地工具，以桌面实验室测量为准，不采集真实用户数据。

- 首屏：本地打开页面到能输入 ≤ 1s（现有产物加上本次改动后）。
- 交互：侧栏切换会话、展开分组、打开菜单的响应 ≤ 100ms（不含网络）。
- 侧栏：一次最多渲染已加载的会话（每页 100 条，最多几页），这个量级不需要虚拟滚动。加载超过 1000 条再考虑。
- 搜索：防抖 250ms；新请求中止旧请求（06 §3.3）。
- 不新增运行时依赖。本次不引入组件库（02 §1）。
- 包体积：gzip 后的 JS 增量 ≤ 15KB。

## 3. 兼容性

- 浏览器：Chrome、Edge、Safari、Firefox 的当前版本和前一个主要版本。
- 宽度：桌面 ≥ 1024px 完整支持；640–1023px 和 < 640px 按 03 §5 保证能用。
- 不支持旧版浏览器，不做 polyfill。

## 4. 安全与隐私

- 设置页（第二批）只显示凭据 Configured / Not set 和变量名，任何地方不显示 key 原文（improve-2 T11）。输入 key 的字段用 `type="password"`、`autocomplete="off"`，保存后清空；key 不进 store 的持久化部分，也不输出到控制台。
- 替换凭据时，密码输入的临时内存和必要的写请求体会包含新值；不要求浏览器开发者工具无法检查用户自己的请求。验收要求读取/写入响应不回显 key，应用日志、控制台、测试报告、持久化存储和错误信息不记录 key 或原始请求正文。
- MCP 的配置和状态只读，Environment / Headers 只显示名字，URL 和失败原因使用服务端已脱敏的文字。Web 不提交 MCP 配置，也不提供凭据输入框。
- 搜索关键词和会话内容不写进 URL；hash 里只有会话 ID、执行目录、设置分区和编辑子页的条目 id 或 MCP 服务器名。
- 消息内容继续经 `marked` + `dompurify` 渲染（沿用现有做法）；搜索片段里的高亮由前端按关键词包裹，片段本身按纯文本处理，不当作 HTML 插入。
- 浏览器存储里只有草稿文字和所选项目（sessionStorage）、置顶、侧栏折叠和上次的设置分区（localStorage），不存 token 和凭据。

## 5. 可观测性

本地工具，不做埋点和错误上报。未知错误显示服务端安全 message；控制台只记录 code、HTTP 状态和非敏感上下文，不序列化完整请求、响应或 Error cause。设置字段错误同样不得包含用户提交的凭据值。
