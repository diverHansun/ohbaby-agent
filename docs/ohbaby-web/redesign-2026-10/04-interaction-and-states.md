# 04 交互与状态

> 页面结构以 [03 §4](03-ui-layout-and-style.md) 的线框为准，流程分支来自 [01](01-use-cases-and-user-flows.md)。视觉表现只写 03 的 token 角色，不写具体数值。

## 1. 组件级状态

| 组件 | 状态 | 表现 | 行为约束 |
|---|---|---|---|
| 会话行 | default / hover / selected / running / awaiting / menu-open / moving | hover：`--bg-hover`，行尾时间换成归档和菜单按钮；selected：`--bg-selected` + 左侧 `--accent` 竖条；running：行尾转圈；awaiting：行尾 `--warning` 圆点；menu-open：保持 hover 样式直到菜单关闭；moving（改归属提交中）：标题旁小转圈 | 行尾只显示一项，优先级：awaiting > running > 时间。hover 出现的按钮不改变行高和标题宽度跳动 |
| 工作区分组标题 | expanded / collapsed / hover / empty | hover：右侧计数换成 `[+]` 和 `[..]`；empty（没有会话）：展开后显示一行灰色的 `No chats`（照 Codex） | 折叠状态写入本地，刷新后保持 |
| 侧栏顶栏格子（New、Search） | default / hover / active | active（搜索展开）：顶部 2px `--accent` 线 + `--bg-selected` | 空间不够时 New 只剩图标，宽度不跳 |
| 输入框卡片 | idle / focused / has-text / submitting / running / steerable / disabled | focused：描边加深；running 且可插话：描边变浅琥珀；disabled（daemon 断开、会话已归档、执行目录不可用）：输入可用，发送按钮不可用。模型未配置不算 disabled（§2.1） | 高度随内容增长，到上限后在框内滚动；IME 输入中按 Enter 不发送（沿用现有逻辑） |
| 发送按钮 | empty / ready / submitting / hidden | 圆形；empty：`--bg-hover` 底、`--text-dim`；ready：`--accent` 底；submitting：转圈，宽度不变，不响应点击 | 运行中且草稿为空时，Stop 占主位（沿用现有规则） |
| 卡片底部控制按钮（模型、思考强度、权限模式） | default / hover / open / disabled | hover 和 open：`--bg-hover`；open 时弹出菜单向上展开 | 按钮宽度随文字变化，最大宽度截断 |
| Stop | default / hover / stopping | 和发送一样的黑色圆钮（D32）；stopping：转圈 | 点击后在请求返回前不可重复点击 |
| 菜单 | open / item-hover / item-disabled / filtering | item-hover 和键盘高亮同一个样式 | Esc：有过滤文字时先清空，再按一次关闭；关闭后焦点回到触发按钮 |
| 工作区选择条（草稿） | default / hover / open | 无边框，hover 才有底色 | 换工作区不清空输入框文字 |
| 审批浮层 | expanded / collapsed / responding / multiple / syncing / sync-error | collapsed：消息区顶部一条；responding：所有选项按钮转圈且不可点；multiple：标题栏显示 `1 / N` 和上一条、下一条；syncing、sync-error：沿用现有提示和 Retry | 浮层出现时焦点移到第一个选项按钮；按钮由后端返回的选项决定，不写死数量；Esc 不作用于审批（避免和输入框的“两次 Esc 停止”冲突），折叠用标题栏的 `[-]` |
| 通知 | entering / visible / leaving | 右上角叠放，左侧类型色点 | 只用于失败和需要用户处理的后台事件（D16）；错误类保留到用户关闭或问题消失。后端发来的说明性通知不显示，例如 key 为 `runtime:model-switch` 的 `Waiting to apply settings`。设置页里的通知出现在主区右上角，位置与对话区相同 |
| 密钥字段（API key） | configured / not-set / editing / cleared | configured：显示 `Configured` + `Replace`、`Clear`；not-set：显示 `Not set` + `Add key`；editing：密码输入框 + `Cancel`；cleared：显示 `Not set`，保存后生效 | 不回显原文；保存成功后输入框清空。没有 key 就是无 key 模式，不另设选项 |
| Save 按钮（设置） | disabled / ready / saving | 没有改动时 disabled；saving：转圈 | 成功后回到 disabled，不显示 `Saved` |

动效只做短过渡，不做弹跳（03 §2）。

## 2. 页面级状态矩阵

### 2.1 主区 · 草稿态（UC-DRAFT-01、UC-DRAFT-02）

| 状态 | 页面表现 | 用户操作 |
|---|---|---|
| 初始 | Lychee 标识 + 工作区选择条（No workspace）+ 输入框卡片，整体居中；焦点在输入框 | 输入、选工作区 |
| 已选工作区 | 选择条显示工作区名；文字保留 | 继续输入、换工作区、发送 |
| 模型未配置 | 平时不提示，发送按钮照常可点；点发送时不创建会话、文字保留，直接打开配置入口（第一批是现有 `/connect` 浮层，第二批是设置 › Models） | 配置模型 |
| 提交中 | 发送按钮转圈；文字已移入消息区 | 等待 |
| 创建失败 | 文字放回输入框，输入框上方显示原因 + `Retry` | 重试、修改 |
| 工作区列表或默认目录读取失败 | 选择条显示 `No workspace`，下拉里一行原因 + `Retry`；不选工作区时发送不可用（拿不到默认目录），选择条旁提示原因 | 重试 |
| daemon 断开 | 对话区顶部一条断开提示；发送按钮不可用 | 等待自动重连 |

### 2.2 主区 · 会话态（UC-SIDEBAR-01、UC-PROJECT-01、UC-CHAT-01）

| 状态 | 页面表现 | 用户操作 |
|---|---|---|
| 加载中 | 顶栏立即显示侧栏里的标题；消息区超过 300ms 未返回时显示一行 `Loading…`，不做骨架屏 | 等待，可切换其他会话 |
| 加载完成 | 消息流滚到底部；顶栏显示标题、工作目录、上下文用量 | 阅读、继续对话 |
| 空会话（只有标题、无消息） | 和草稿态相同的居中布局，但没有工作区选择条 | 输入 |
| 运行中 | 消息流增量追加；草稿为空时主操作位是 Stop，有草稿时按现有规则发送插话或排队 | 插话、排队、停止 |
| 等待审批 | 审批浮层出现在消息区；侧栏该会话行显示琥珀点 | 允许、拒绝、折叠 |
| 换工作区待生效 | 不额外提示；顶栏仍显示当前目录，下一轮开始后更新 | 正常继续 |
| 发送失败 | 文字放回输入框，输入框上方显示原因 + `Retry`（沿用现有发送失败恢复规则） | 重试 |
| 执行目录不可用 | 消息区显示原因 + `Move to workspace…` 文字按钮（打开该会话的工作区列表）；输入框不可发送 | 换工作区 |
| 加载失败 | 消息区居中一行原因 + `Retry` | 重试 |
| 会话已移动 | 无可见变化；runtime 自动换目录重发（最多 2 次，仍失败按发送失败处理） | — |
| daemon 断开 | 同 2.1 | 等待 |

### 2.3 侧栏（UC-SIDEBAR-01、UC-SIDEBAR-02、UC-SESSION-01、UC-PROJECT-03）

| 状态 | 页面表现 | 用户操作 |
|---|---|---|
| 首次加载 | 字标、New、Search、Settings 立即可用；会话树位置超过 300ms 未返回时显示一行 `Loading…` | 可直接新对话 |
| 加载完成 | Pinned（有置顶才显示）→ Workspaces → Recents（不能折叠） | 浏览、打开 |
| 全新用户（无工作区、无会话） | 只有 Workspaces 标题和它旁边常驻的 `[+]`，不放说明文字；Recents 不显示 | 打开文件夹，或直接在主区对话 |
| 某组还有更多 | 组尾 `Show more · N`；已展开过时并排 `Show less` | 加载更多 |
| 加载更多中 | `Show more` 换成转圈，不可重复点击 | 等待 |
| 刷新中（重新激活、重连） | 保留旧列表，不闪烁；完成后原地更新 | 正常使用 |
| 加载失败 | 没有任何数据时，会话树位置一行原因 + `Retry`；旧数据还在时保留旧数据、不提示，下次触发时再刷新 | 重试 |
| 工作区列表失败、会话列表成功 | 会话照常显示，按 `workspaceDirectory` 用目录名临时分组（06 §2）；Workspaces 标题旁一个小的错误图标，点击重试 | 重试 |
| 当前打开的会话属于被隐藏的工作区 | 服务端列表不返回它，侧栏里没有这一行；主区照常显示。从搜索打开时也是这样 | 正常使用 |
| 归档后 | 行立即消失，不另外提示，也不弹 Undo；恢复入口在 Settings › Archived | — |
| 会话运行中或等待审批 | 悬停的归档按钮和菜单里的 Archive 置灰，提示 `Stop the chat before archiving`，菜单项后标 `Running`。其他工作区的会话侧栏不知道运行状态，靠服务端返回 409，通知显示同一句话 | 先停止 |
| 收起 | 宽度过渡到 0；主区顶栏的 `[=]` 可展开 | 展开 |

“归档后行立即消失”是对列表的本地处理，等服务端确认后再刷新；失败时行恢复并显示错误通知。这是侧栏唯一的先改后确认，不涉及会话内容，不违背“会话真相不做乐观更新”。

### 2.4 侧栏搜索（UC-SEARCH-01）

| 状态 | 页面表现 | 用户操作 |
|---|---|---|
| 打开 | 搜索框获得焦点；框为空时下面仍是会话树 | 输入 |
| 查询中 | 结果区顶部细转圈，保留上一次结果 | 继续输入 |
| 有结果 | 单行列表，标题命中在前；正文命中多一行片段；命中词高亮 | ↑↓ 选择、Enter 打开 |
| 无结果 | `No chats match "<关键词>".` | 改关键词 |
| 有更多 | 列表底部 `Show more results` | 加载下一页 |
| 失败 | 一行原因 + `Retry`，关键词保留 | 重试 |
| 关闭 | Esc 或再点 Search 格；关键词清空，恢复会话树 | — |

### 2.5 会话菜单与工作区列表（UC-PROJECT-01、UC-PROJECT-02、UC-SESSION-01）

| 状态 | 页面表现 | 用户操作 |
|---|---|---|

| 导出格式 | 原菜单位置换成 HTML、JSONL 两项（沿用现有导出能力） | 选择、Esc 回到上一级 |

| 提交中 | 菜单关闭；该会话行标题旁一个小转圈 | 等待 |
| 成功 | 行移动到目标分组并保持选中 | — |
| 失败 | 行留在原处；右上角错误通知写明原因 | 重试 |

### 2.6 设置页（UC-SETTINGS-01 至 06，第二批）

**共用规则**

| 状态 | 页面表现 |
|---|---|
| 打开 | 点齿轮打开设置弹窗，显示上次的分区（第一次是 Models）；焦点移入弹窗 |
| 离开 | × 或 Esc 关闭弹窗，焦点回到齿轮；点遮罩不关闭；编辑页内的返回只回所属列表。弹窗不进 URL，浏览器后退不负责关闭它 |
| 分区加载中 | 超过 300ms 显示一行 `Loading…` |
| 分区加载失败 | 只有该分区显示原因 + `Retry`，其他分区正常 |
| 有未保存修改时离开 | 不拦截、不弹确认框。关闭弹窗时保留弹窗状态（所在分区、编辑子页和输入），本次页面内再次打开时原样恢复；切到其他分区或刷新页面后丢弃 |
| 保存中 / 成功 / 失败 | Save 转圈 / 回到列表（编辑子页）或 Save 回到不可点（单页表单），不显示 `Saved` / 出错字段下写原因，保留输入；没有字段信息的错误写在 Save 旁 |
| 别处改了设置 | 收到 `settings.changed` 时重新读取当前分区（只在已连接实例时能收到）；另外每次进入分区、窗口重新激活时也重新读取；编辑子页里有未保存的输入时不覆盖输入 |

**Models**

|---|---|---|
| 没有模型 | 列表位置一行 `No models yet.`；`Add model` 在顶栏右侧 | 新增 |

| 行菜单 | Set as default（当前默认或 Needs setup 时没有这一项）、Delete | 选择 |
| 设为默认中 | 该行行尾转圈；成功后 `Default` 移到这一行 | 等待 |
| 设为默认失败 | 该行下方一行原因，行菜单里可以再试 | 重试 |
| 删除普通模型 | 不弹确认；请求中该行操作不可点，成功后删除行，失败时行保留并显示原因 | 重试 |

| 编辑子页 · Needs setup | 填好已知字段；API key 按实际显示 Configured / Not set；Base URL 或 Protocol 缺失时 Save 不可点，填齐后即使没有其他改动 Save 也可点；保存后条目变为完整 | 补齐后保存 |
| 条目已不存在（别处删了） | 回到列表，列表已刷新，不另外提示 | — |

**MCP**

| 状态 | 页面表现 | 用户操作 |
|---|---|---|
| 没有服务器 | 一行 `No MCP servers.`；顶栏保留 Refresh | 刷新 |
| 状态读取中 | 列表先按全局配置显示，状态位置空着；超过 300ms 显示小转圈 | 等待，可展开配置 |
| 正常 | 每行：名称、状态文字（`N tools` / `Failed` / `Off` / `Not connected` / `—`）。配置里停用的一律显示 Off；配置启用但状态为 disabled/disconnected 时显示 Not connected，无状态数据时显示 `—` | 展开、收起 |
| 状态读取失败 | 列表照常显示配置，状态位置写 `—`，Refresh 旁一行原因 + Retry | 重试 |
| agent 修改配置后 | 重新进入、窗口激活或 Refresh 时读取最新配置和实际状态；连接仍可能沿用旧配置，不伪装成已生效，不额外提示 | 查看、刷新 |
| Refresh 中 | 保留已有配置，按钮转圈且不可重复点击；只发读取请求 | 等待、展开详情 |
| 展开详情 | 配置、实际状态、已脱敏失败原因和 Tools 列表均为只读文本；Environment / Headers 只列名字，不显示值 | 收起 |

MCP 不提供添加、编辑、删除、启停、重连或手动调用工具的操作。Refresh / Retry 只读取数据，修改配置继续交给 ohbaby（D25）。

**Archived**（UC-SETTINGS-06）

| 状态 | 页面表现 |
|---|---|
| 加载中 | 超过 300 ms 才显示 `Loading…`；每次进入分区都重新读取，不进设置缓存 |
| 读取失败 | 一行原因 + `Retry`；`Show more` 失败时原因显示在按钮下方，已加载的行保留 |

### 2.7 右侧栏 · Subagents（D33）

| 状态 | 页面表现 | 用户操作 |
|---|---|---|
| 没有打开任何页面 | 入口页：一行 Subagents 入口 | 打开 Subagents |
| 还没有打开的会话（新对话草稿） | 一行 `Open a chat to see its subagents.` | — |
| 列表加载中 | 超过 300ms 才显示一行 `Loading…` | 等待 |
| 列表为空 | 一行 `No subagents in this chat.` | — |
| 某个分组为空 | 分组标题下一行 `None`（淡色） | — |
| 列表刷新失败 | 保留上一份列表，顶部一行原因 + `Retry`；第一次就失败时只显示这一行 | 重试 |
| 详情：读取中、断线重连、读取失败 | 提示行：`Loading…`、`Reconnecting…`、原因 + `Retry` | 等待、重试 |
| 详情：实例还没有任何执行 | 一行 `Not started yet.` | 返回列表 |
| 详情：运行中 | 顶部有 `Stop` | 停止、返回列表 |
| 详情：正在停止或收尾 | `Stop` 变成禁用的 `Stopping…` | 返回列表 |
| 详情：停止失败 | 顶部一行原因；按钮恢复 | 重试停止 |
| 正在看的实例被 close | 自动退回列表，实例从列表里消失；不弹通知（D16） | — |
| 切换主会话 | 右侧栏保持打开，回到新会话的列表 | — |
| 从列表回到刚看过的实例 | 沿用已经加载的内容和滚动位置，不重新定位到派遣开头 | — |
| 点主会话里 agent 工具卡下的入口行 | 展开右侧栏：当前 Tab 是 Subagents 就用它，否则用第一个 Subagents Tab，都没有就新开；直接进入这个实例并定位到这次派遣。同一个入口再点一次会再定位一次。主输入框和审批照常可用 | 返回列表、切换实例 |
| 入口行对应的实例被 close | 入口行撤下，工具卡保留；实例快照读取失败时保持原样 | — |

## 3. 交互语义

- **点击**：会话行单击打开；工作区分组标题单击折叠或展开；不使用双击。
- **右键**：会话行右键等同于点 `[..]`，菜单出现在鼠标位置。
- **快捷键**：本轮只新增一个，`Cmd/Ctrl + K` 打开侧栏搜索（侧栏收起时先展开）。新对话、收起侧栏、打开设置都用按钮，不加快捷键：常见组合（`Cmd+Shift+O`、`Cmd+,`、`Cmd+B`）在浏览器里多被占用，不一定能拦截。
- **Esc**：一次只关一层，由当前焦点所在的那一层处理：
  1. 菜单打开时，关菜单（有过滤文字时先清空）
  2. 焦点在搜索框时，收起搜索
  3. 焦点在输入框时，沿用现有逻辑（关斜杠命令面板；运行中两次 Esc 停止）

  Esc 不作用于审批浮层。全局监听不接管输入框里的 Esc。
- **输入框**：Enter 发送，Shift+Enter 换行，`/` 开头打开斜杠命令面板（沿用现有逻辑）。
- **焦点**：菜单、审批浮层打开时焦点进入；关闭时回到触发元素。新对话后焦点在输入框。切换会话后焦点在输入框。
- **确认**：归档、移出工作区、换工作区都不弹确认，和现在的行为一致。归档不在原地撤销（恢复要去 Settings › Archived），所以菜单里 Archive 放在分隔线下方，和其他项分开。设置里删除模型（2026-10-26 起单个模型也确认）、删除整个 provider、永久删除已归档会话弹确认（D17、归档会话议题 D9）；确认框的焦点默认在 Cancel 上。
- **防重复**：所有提交在请求返回前不可再次点击；发送沿用现有的 admission 规则。
- **通知**（与 02 §6 一致）：和当前位置有关的错误在原地提示；操作成功不提示；不在原地的失败和需要用户处理的后台事件用对话区右上角的通知。
- **加载提示**：300ms 内返回的不显示加载状态，避免闪烁。
- **操作后的落点**：新对话发出后停在该会话；换工作区后停在原会话；归档当前会话成功后回到草稿态，失败保持原对话。

无障碍基线见 07：全部操作可用键盘完成，焦点可见，状态不只靠颜色。
