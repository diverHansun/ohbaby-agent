## 原生浏览器端到端操作

使用实际构建的 Web、真实 CLI daemon 和临时 profile，通过浏览器控制完成点击、输入、滚动、菜单选择和刷新。模型端为本地 OpenAI-compatible 测试服务；文件读取、会话创建、压缩、恢复和设置读取仍走真实服务端。临时代理仅用于制造断连和一次归档失败。没有调用外部模型或搜索供应商，没有修改个人配置。

| 场景 | 实际结果 |
|---|---|
| 草稿欢迎区与提示文字 | 显示按时间生成的问候和新的输入提示 |
| Slash 键盘操作 | `/st` + Tab 补成 `/status`，Enter 打开真实状态结果；菜单有六项 |
| 真实发送与工具 | 首发创建会话，真实 `read` 工具读取 100 行本地文件，随后流式显示回复 |
| 流式滚动 | 主区向上滚动后追加内容，位置保持；回到底部后再次追加，恢复跟随 |
| MCP 失败状态 | 缺失的测试命令显示 failed 和失败原因；错误文字为红色 |
| `/compact` 与 `/goal` | Compact 主按钮获得焦点，第二次 Enter 执行并关闭；Goal 显示空状态和禁用的空目标提交按钮 |
| 断连与恢复 | 只出现一处 `Reconnecting…`，没有重复错误 alert；恢复连接后提示消失 |
| 操作失败 | 模拟归档失败后显示可读错误，Dismiss 可关闭，原会话仍在 |
