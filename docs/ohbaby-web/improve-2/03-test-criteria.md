# 03 本模块验收重点

- **恢复（T09–T12、T22、T23）**：延迟快照、持续输出、切项目、断网、双页面及已加载历史；当前值与后续变化不断裂，阅读位置保留。
- **操作与降级（T13、T19、T24、T28、T29）**：草稿不自动发送、未知 receipt 不重发、确切 Stop、审批独立；展示思考失败和超限缺失可见且不变更 run 结果。
- **旧链退场（T31）**：初次/重连和模型/索引刷新均不经旧整页替换；注入旧事件不覆盖新会话。
