# 02 本模块责任与交接

**拥有**：先订阅并缓存当前会话事件，再安装同切点完整值，按连续 revision 应用后续变化；旧响应及另一范围的事件不能覆盖当前页面。保留按需加载的旧历史和阅读位置，附加读取局部失败。初次连接/重连不再自造整页 replacement；模型和索引更新按自身范围刷新。

**能力条件**：草稿可写；发送等待本会话核心恢复和控制准入；Stop 只要确切目标及控制通路可用；审批只依 improve-1 的独立同步。展示思考保存失败或超限缺失需明确提示，不误写 run 结果，也不因此长期锁发送。

**边界**：未来子会话只读页面属于 improve-3，本轮不建立子会话提示词或审批入口。

具体字段、容量、初始化顺序和旧路径清单以[中央 02](../../problem-lists/2026-09-19-execution-reliability/improve-1.1/02-optimization-plan-and-change-scope.md)为实施契约。实施差异在中央 05 验收记录，不把本页当成独立协议。
