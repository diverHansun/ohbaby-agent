# 04 交互与状态

页面结构以 [03 §4](03-ui-layout-and-style.md#4-线框) 的线框为准，文案以 [03 §5](03-ui-layout-and-style.md#5-内容与文案) 为准。

## 1. 组件级状态

### 1.1 Cancel 按钮

| 状态 | 表现 | 触发 |
|---|---|---|
| default | 文字 `Cancel`，`--text-dim`，没有边框和底色 | 任务 `running` 且 `canStop` |
| hover | 文字变为 `--text`，出现 `--bg-hover` 浅底 | 鼠标悬停 |
| focus-visible | 现有焦点环（`--focus-ring`） | 键盘聚焦 |
| cancelling | 文字 `Cancelling…`，变淡，不响应点击，**宽度不变**（按较长的文案预留宽度） | 已发出取消请求，后端状态还是 `running` |
| 不显示 | 整个按钮不渲染，位置留给时长 | 任务不是 `running`，或 `canStop` 为 false（见 00 §4） |

行为约束：

- 点击 Cancel 不会冒泡到行，不会进入详情。
- 同一任务在列表和详情里共享 cancelling 状态：在列表点了 Cancel 再进详情，详情里也是 `Cancelling…`。
- cancelling 只在本页面内存里；刷新页面后以后端状态为准。

### 1.2 列表行

| 状态 | 表现 |
|---|---|
| default | 说明 + 命令（+ 启动者）；右侧时长或失败字样，运行中再加 Cancel |
| hover | 整行 `--bg-hover` |
| focus-visible | 整行焦点环 |
| 刚出现 | 新行直接出现，不做插入动画，避免列表跳动 |

### 1.3 组标题

`Running 2` / `Done 3`，可点击折叠，带朝右的小箭头，展开时箭头转向下。折叠只是阅读上的方便，切换会话后重置为展开。组内为空时组标题照常显示，内容为一行灰字 `None`，和 Subagents 页一致。

### 1.4 输出区

| 状态 | 表现 |
|---|---|
| 贴底跟随 | 新输出到达时自动滚到底 |
| 已离开底部 | 停止自动滚动；右下角出现“回到底部”圆形小按钮 |
| 点回到底部 | 滚到底，按钮消失，恢复跟随 |
| 空 | 运行中：输出区留空白，不显示文字；结束且没有输出：灰字 `No output.` |
| 没有保存输出 | `No output was saved for this task.` |

“离开底部”的判定留一点余量（初值 24px），不要因为一两像素的误差就停止跟随。

### 1.5 入口行

| 状态 | 表现 |
|---|---|
| default | 小图标 + `Background task` + `›`，淡色 |
| hover / focus-visible | 和 `DelegationRow` 一致 |

文字不随任务状态变化（README D6）。

### 1.6 动效

- 列表进入详情：内容区短促横向滑入，返回时反向；初值约 150ms，遵守 `prefers-reduced-motion`（关闭位移，只保留淡入）。
- Cancel → Cancelling…：文字淡入淡出，不改变宽度。
- 时长：运行中的行每秒更新，用等宽数字，不做翻牌动画。
- 其他状态变化（行移到 Done 组等）不做动画。

## 2. 页面级状态矩阵

### 2.1 Background tasks 入口（`[+]` 菜单、入口页、Tab 本身）

| 状态 | 表现 |
|---|---|
| 确认会话没有任何任务 | 菜单和入口页不显示这一项；已打开的 Tab 隐藏 |
| 探测还没回来（含刚切换会话） | 保持上一次的显示状态，不变化；应用刚打开、从没有结果时，菜单里不显示这一项 |
| 探测失败 | 保持上一次的显示状态；下一次失效事件或重连时再探测 |
| 确认会话有任务 | 菜单和入口页显示这一项；隐藏的 Tab 重新出现 |

只有拿到确定的结果才改变显示，避免切换会话或重连时 Tab 闪一下、选中项跳走。Tab 被隐藏时如果正被选中，选中规则沿用 Side chat Tab 隐藏的现有实现（`use-side-panel.ts`）。隐藏不等于关闭：重新出现时还在原位置。

### 2.2 列表视图

| 状态 | 表现 | 用户操作 |
|---|---|---|
| 首次加载 ≤300ms | 空白，不闪 | 等待 |
| 首次加载 >300ms | 一行 `Loading…` | 等待 |
| 加载成功，有任务 | Running 组 + Done 组 | 查看、取消、进入详情、筛选 |
| 筛选后为空 | 一行灰字，见 03 §5.4；组标题不显示 | 换筛选 |
| 首次加载失败 | 一行错误说明 + `Retry` | 重试 |
| 刷新失败（之前有数据） | 保留旧列表，顶部一行错误说明 + `Retry` | 继续查看旧数据、重试 |
| 后台刷新中（收到失效事件） | 保留旧列表，不显示加载状态，新数据到了直接替换 | 照常操作 |
| 滚到底部附近，还有下一页 | 自动加载；超过 300ms 才在列表末尾显示一行 `Loading…` | 继续滚动 |
| 加载下一页失败 | 列表末尾一行错误说明 + `Retry`；不再自动重试，避免滚动时反复报错 | 点 Retry |
| 没有下一页 | 什么都不显示 | — |
| 取消失败 | 列表顶部一行错误说明（不带 Retry），该行恢复 Cancel | 再点 Cancel |
| 会话切换 | 回到默认筛选和展开状态，重新加载 | — |

排序的一个副作用：后端把“已结束但还没收尾完”和“清理未确认”的任务也算作需要关注，排在 Done 组最前面。所以一个刚结束的任务可能先出现在 Done 组顶部，几秒后收尾完成，再移到按时间排的位置。这是预期行为，前端不重新排序，也不为它加标记（D3）。

### 2.3 详情视图

| 状态 | 表现 | 用户操作 |
|---|---|---|
| 进入时行数据已在列表里 | 标题区立即显示；输出区等第一次输出返回 | 查看、取消 |
| 从入口行进入，行数据还没有 | 标题区先显示返回按钮；超过 300ms 显示 `Loading…` | 等待、返回 |
| 运行中 | 状态行实时走秒；输出每 2 秒刷新、贴底跟随；页面切到后台时暂停 | 取消、滚动、复制 |
| 已结束 | 状态行显示结束状态；输出只拉一次 | 滚动、复制、返回 |
| 取消中 | `Cancelling…`；输出照常刷新 | 返回 |
| 任务不存在 | 标题区只剩返回；内容为 `This task is no longer available.` | 返回 |
| 输出拉取失败 | 输出区上方一行错误 + `Retry`；已有输出保留；轮询暂停，点 Retry 后恢复 | 重试、返回 |
| 取消失败 | 标题区下方一行错误说明（不带 Retry），恢复 Cancel | 再点 Cancel |
| 由别的后端管理（仅运行中） | 没有 Cancel；说明行见 03 §5.3；输出来自已保存的检查点 | 查看 |
| 清理未确认 | 说明行见 03 §5.3；不提供重试清理或“放弃追踪” | 查看 |
| lost | 状态行 `Result unknown`；说明行见 03 §5.3 | 查看 |
| 输出超过 32KiB | 输出区第一行 `Showing the last 32 KB.`；有日志路径时带复制图标 | 复制路径 |
| 日志被截断 | 再加一行 03 §5.4 的说明 | 查看 |
| 没有保存输出尾部 | 输出区显示 `No output was saved for this task.` | 查看 |

### 2.4 bash 工具卡入口行

| 状态 | 表现 |
|---|---|
| 工具调用进行中 | 不显示 |
| 结果里有 `jobId` 且 `mode` 为 `background` | 显示入口行 |
| 前台命令、或没有 `jobId` | 不显示 |
| 旧会话里的 bash 结果（没有 `mode` 字段） | 不显示 |

### 2.5 主会话对话流

| 消息 | 表现 |
|---|---|
| `runtimeInputKind` 为 `background-task-result` | 不渲染（和 `subagent-result`、`subagent-status` 同样处理） |
| 被它唤醒的那一轮的助手回复 | 照常渲染；上方没有用户气泡。轮次末尾沿用 SDK 已有的小标签 `Background task update`，和子代理唤醒的 `Subagent update` 一致 |
| 该轮的运行过程（工具调用折叠组） | 照常渲染 |

权限相关状态：单角色，不适用（见 01 §1.3）。

## 3. 交互规则

- **单击**：列表行单击进入详情；没有双击语义。
- **键盘**：
  - 列表行和 Cancel 都在 Tab 顺序里，行先于它的 Cancel。
  - Enter / Space 激活当前焦点元素。
  - 详情页里 Escape 不返回列表（Escape 已用于退出右侧栏展开状态，redesign-2026-10 03 §4.9），返回用返回按钮。
- **焦点**：
  - 进入详情后焦点落在返回按钮。
  - 返回列表后焦点回到刚才那一行；那一行不在了就落在列表容器上（和 Subagents 页一致）。
  - 从入口行打开详情时，焦点留在对话里，不抢到右侧栏。
- **取消确认**：不确认。理由：只影响一个任务；模型会收到用户取消的通知，可以重新启动。
- **防重复提交**：Cancel 点击后立即进入 cancelling，后续点击无效。
- **成功反馈**：取消成功不弹 Toast；行移到 Done 就是反馈（redesign-2026-10 D16“少提示”）。
- **Toast**：本功能不使用 Toast，所有错误都显示在出错的位置。
- **加载**：300ms 内不显示加载状态。
- **复制**：命令和输出可以直接选中复制；日志路径用图标按钮复制，复制后图标短暂变成对勾，不弹提示。
- **无障碍**：
  - 列表是带 `aria-label` 的分组列表，组标题按钮带 `aria-expanded`。
  - 失败行的红字是真实文字，不只靠颜色。
  - 运行时长每秒变化，不放进 live region，避免读屏器每秒播报。
  - 取消完成后，行移动不额外播报。
