# 09 Web 后台任务验收

2026-11-14 验收，基线 `6f1c7f22`。范围为 Web 的任务菜单、列表、详情、单任务取消、Bash 卡入口及后台结果消息。后端沿用 improve-1～3。本轮新增用户列表的可选 `mode=background`，游标绑定该过滤条件，模型 `task(list)` 的前台清理异常仍可查。

## 真实 Web 与模型

使用编译产物启动 ohbaby daemon，绑定本机回环地址。临时工作区和数据库独立于日常会话，沿用现有 API key 配置，由 `deepseek/deepseek-v4.1-flash` 实际发出工具调用。内置浏览器通过单次授权运行以下命令，检查 DOM 和截图，并以数据库中的任务事实交叉核对。

| 流程 | 观察结果 |
| --- | --- |
| 显式后台、工具入口、输出与取消 | 展开 Bash 工具卡后打开详情，连续读取到增长的 `WEB_E2E_TICK`；从详情取消，显示 `Cancelled by you` 并移到 Done。数据库为 `cancelled/user/confirmed`。 |
| 自动转后台及正常完成 | `wait_ms=100` 的 3 秒任务进入后台，详情显示 `Completed · exit 0`，尾部含 `REAL_PROMOTED_OK`，持久记录含转换和结果就绪时间。 |
| 自动转后台及硬超时 | `timeout=1500` 的长任务显示红色 `Timed out`，详情含 `REAL_TIMEOUT_START`。记录保留 1500 毫秒截止、`timeout` 原因与清理确认。 |
| 失败退出 | 列表显示红色 `Failed`，详情显示 `exit 7` 及 `REAL_EXIT_7`。 |
| 子代理归属 | 实际委派的独立子代理启动后台命令。Main agent 显示四条，Subagents 显示一条及启动者，详情可读 `REAL_CHILD_JOB_OK`，All 显示五条。 |
| 最终构建与持久读取 | 完整检查构建结束后重新载入真实会话，主代理和子代理记录仍按作用域读取，All 显示 Done 5。 |

开始时内置浏览器连接超时，使用应用的 Playwright 浏览器打开过初版和确定性模型替身，验证了前台命令无入口及输出增长、取消。在用户要求切换后，后续浏览器操作、真实 API 路径和截图均使用内置浏览器的 Computer Use。

## 场景与回归

- 浏览器走查 `bg-none`、`bg-running`、`bg-subagents`、`bg-subagents-only`、`bg-two-chats`、`bg-many-done`、`bg-special`、`bg-cancel-errors`、`bg-output-fail`。覆盖前台过滤、默认筛选、切换会话、列表分组、连续分页、详情返回与焦点。
- 250 条列表实际滚动到最后一条。进入详情并返回后，最后一条仍在视口内并重新获得焦点。复查列表在刷新中保持已加载范围由 SDK 测试覆盖。
- 有效制造异后端、任务不存在、清理冲突及输出读取失败。确认拒绝后撤下无效 Cancel、显示不可用、显示清理提示，以及 Retry 后恢复输出。截断、日志复制反馈及丢失状态均在浏览器中走查。
- 截图检查 1440 像素桌面与 390 像素窄屏。任务行保留命令省略，窄屏可点击 Cancel 并立即进入禁用的 Cancelling 状态。后台结果输入不进入主消息流，唤醒产生的回复仍可见，现有组件集成测试覆盖过滤和工具卡入口。
- 不把所有模拟异常记为真实 API 实测。后台标签暂停、结果未排空、失效节流、失败分页停等和乱序保护由定向测试验证。延迟提示阈值和按钮像素宽度未逐项计时测量。浏览器走查使用当前 macOS 环境。

## 验收修正

| 发现 | 修正 |
| --- | --- |
| 排定的输出请求在隐藏后仍会发出，逻辑终态可能早于尾部就绪 | 发请求前检查可见性，保持单请求。继续读取到 `resultReadyAt` 有值，再停止轮询。 |
| 分页失败被失效刷新清除，触发自动重试 | 保留下一页错误，等待主动 Retry，或确认已无下一页。 |
| 旧列表行遮住不存在状态，异后端拒绝后仍可点 Cancel | 以明确拒绝更新详情及列表，并重读后端事实。 |
| 详情销毁列表 DOM，返回时焦点落在屏外 | 保持列表及折叠状态，详情显示期间暂停分页观察，返回时恢复可见焦点。 |
| 侧聊继承主会话任务入口，历史卡片临时显露入口后不能恢复隐藏 | 侧聊使用自己的范围，移除主会话 opener。仅在任务详情存在时临时显露历史入口。 |
