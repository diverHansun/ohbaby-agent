# Mermaid 图表：非功能约束

> 前置：[goals-duty.md](goals-duty.md)、[dfd-interface.md](dfd-interface.md)。
>
> 下面的数字都来自 2026-11-23 的本机测试，环境是 Chrome、Pele 1.13.0、Mermaid 12.1.0。Safari 和 Firefox 还没有测，列在 [test.md](test.md) 的验收项里。

## 1. Quality Priorities（质量优先级）

1. **安全**：模型内容不能在页面里执行或发起外部请求。
2. **聊天不受影响**：没有图时零额外下载，绘图失败不影响消息显示。
3. **可读**：文字清楚，宽图可滚动，风格和界面一致。
4. **图表能力**：覆盖常见图类型，高级功能留到需要时再做。

## 2. Operational Constraints（运行约束）

### 依赖

- `apps/ohbaby-web` 的运行时依赖新增 `pele`，**精确锁定 `1.13.0`**，不用 `^`。Pele 发版很快，1.7.0 到 1.13.0 只隔了 12 天，1.7.0 还有吞掉 `<string>` 这类标签的问题。
- [2026-10 改版的质量约束](../redesign-2026-10/07-quality-constraints.md)里写了“不新增运行时依赖”，那条只约束那次改版。Pele 是本议题单独确认引入的依赖。
- 升级 Pele 时必须重跑 [test.md](test.md) 的 U 组和 B 组。

### 体积

| 项目 | 约束或实测 |
|---|---|
| 首屏 JS 增量 | gzip 后不超过 15KB，只含识别和挂载代码，沿用改版时的上限 |
| 没有图的会话 | 不下载 Pele |
| 第一张流程图 | 下载约 67KB（gzip），官方 Mermaid 约 643KB |
| 全部图类型 | 约 295KB（gzip），官方 Mermaid 约 1470KB |

### 输入限制

单个代码块的源码超过 **20,000 个字符**时不绘制，直接显示代码。这个数值和 ZCode 相同，但 ZCode 的预算是为了防 Mermaid 和 DOMPurify 内存溢出，所以这里单独按 Pele 测了一遍。

把链式、密集连线、子图、时序图和类图各写到接近上限，在 Chrome 里测绘制、清洗和挂载的总耗时：中位数 25 到 53ms，最慢一次 90ms，生成的 SVG 为 382 到 699KB。单张图不会造成明显卡顿，所以不再加行数和复杂度预算。

一条消息里放多张接近上限的图时，耗时会累加。这种内容很少见，暂时不分帧。

### 性能

307 个来自 `code-cli/` 文档的真实图，其中 300 个两个库都能画，另外 7 个源码本身有语法错误：

| 指标 | Pele 1.13.0 | Mermaid 12.1.0 |
|---|---|---|
| 单图中位数 | 0.5ms | 15.0ms |
| 单图 P95 | 1.9ms | 33.9ms |
| 单图最大值 | 24.0ms | 490.2ms |
| 500 节点流程图 | 7.2ms | 845ms |
| 200 条消息的时序图 | 2.4ms | 60.9ms |

Pele 在主线程计算。按这个速度不需要 Worker，也不需要分帧。一条消息放 30 张普通大小的图，原型总耗时约 15ms。

### 安全

- 只增强带本页随机标记的代码块。
- 调用 Pele 时关闭链接和图片。
- SVG 插入页面前用 DOMPurify 的 SVG 配置清洗。
- 不使用 Mermaid 的 HTML 标签模式。

14 个恶意样例在 Pele 上都没有执行脚本，也没有产生外部请求。

### 无障碍和兼容

- 切换按钮是真实的 `<button>`，有 `aria-label`，键盘聚焦时可见。
- 桌面点击区域 24×22px；触屏点击区域 44×44px，视觉大小不变，Copy 相应左移，避免两个点击区重叠。
- 宽图可以用键盘聚焦和滚动，做法和宽表格一致。
- 浏览器范围沿用 Web 现有约定：Chrome、Edge、Safari、Firefox 的当前版本和前一个主要版本。

## 3. Reliability & Observability（可靠性与可观测性）

- 任何绘制失败都退回代码块，不向外抛错，也不影响同一消息里的其他图。
- 组件卸载或内容变化后，晚到的绘制结果被丢弃。
- 不新增埋点。失败时不写控制台，因为错误信息可能带上消息内容，这和 Web 现有的日志约定一致。
- 需要排查时，看代码块上有没有 `data-mermaid-state="ready"`，再把源码单独放进 Pele 复现。

## 4. Trade-offs & Deferred Requirements（取舍与暂缓项）

| 取舍或暂缓 | 现在的做法 | 什么时候重新考虑 |
|---|---|---|
| 非官方绘图库 | 精确锁版本，升级时重跑对比 | 出现大量官方语法不支持，或者项目停止维护 |
| 图的布局和官方不同 | 接受，真实样本里没有单边失败 | 用户反馈某类图明显难读 |
| 缩放、全屏、导出 | 不做 | 大图经常读不清 |
| 文件预览里画图 | 不做，保留开关 | 用户需要预览 `.md` 里的图 |
| 深色模式 | 不做，颜色已走 token | ohbaby 引入深色模式 |
| 触屏上的 Copy 点击区 | 沿用现有 22px，不在本模块修改 | 单独优化代码块按钮时 |
