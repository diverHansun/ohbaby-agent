## 1. Design Goals（设计目标）

1. **回答完成后能直接看图。** 助手用 Mermaid 写的流程图、时序图等显示成图，中文和 `Promise<string>` 这类标签不丢字。
2. **不拖慢普通聊天。** 没有图的会话不下载绘图代码。有图时，绘制不让页面出现可感知的卡顿。
3. **图画不出来时不打扰阅读。** 用户仍然看到原来的代码，页面上不出现红色报错。
4. **模型输出不可信。** 图里不能运行脚本，不能请求外部资源，也不能靠伪造的 HTML 冒充图表。
5. **和 ohbaby 的界面风格一致。** 图直接放在文字流里，不加卡片外框，颜色和字体跟随现有设计 token。

## 2. Duties（职责）

| 编号 | 职责 | 怎样算做到 |
|---|---|---|
| R1 | 识别真实的 Mermaid 代码块 | 只处理渲染器自己写出、语言为 `mermaid` 或 `mmd` 的代码块；模型手写的同名 HTML 不生效 |
| R2 | 在正确的时机绘制 | 只有助手消息结束输出后才绘制，输出过程中显示代码 |
| R3 | 按需加载绘图库 | 页面里第一次出现要绘制的图时才下载 Pele |
| R4 | 失败时保留代码 | 语法错误、未知图类型、内容超长、绘图库加载失败时，代码块保持原样 |
| R5 | 保留源码 | 画成图以后，Copy 仍复制 Mermaid 源码；用户可以在图和代码之间切换，切换不重新绘制 |
| R6 | 隔离不可信内容 | 插入页面的 SVG 经过清洗，不含脚本、事件属性、外部图片和可点击链接 |
| R7 | 跟随设计 token | 图的文字、线条、填充和边框使用 ohbaby 的颜色和字体变量 |
| R8 | 处理宽图 | 图按原始大小显示，比容器宽时只在图内横向滚动，页面不出现横向滚动条，键盘也能滚动 |
| R9 | 在 React 更新中保持稳定 | 内容不变时不丢图、不重复绘制；内容变化时重新绘制；组件卸载后不再写 DOM |

## 3. Non-Duties（非职责）

- **不在输出过程中绘图。** 半截语法容易报错，图也会反复变形。
- **不处理其他位置的 Markdown。** 用户消息、命令结果、文件预览、思考内容和工具输出都继续显示代码。文件预览以后想打开，只需要传一个开关。
- **不做缩放、全屏和导出图片。** 真实使用中觉得不够再加。
- **不做深色模式。** ohbaby 现在没有深色模式。颜色已经走 token，以后加主题时不用重新绘制。
- **不修复模型写错的语法，也不提示错误原因。** 用户看到的是原始代码。
- **不记住用户的切换选择。** 组件重新挂载后回到看图状态。
- **不负责 Markdown 解析、流式更新和通用排版。** 这些分别属于上面的相关议题。
- **不做 TUI 渲染。**
