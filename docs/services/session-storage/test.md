# test

> 2026-11-04。遵循仓库现有约定：测试与源码同目录，`*.unit.test.ts`、`*.integration.test.ts`、`*.contract.test.ts`；测试通过临时的 `HOME` / `OHBABY_HOME` 隔离（`tests/setup/vitest-env.ts`）。

## 1. Test Scope

| 范围 | 覆盖 |
|---|---|
| unit | 路径计算与 ID 校验；归属规则；第二期的输出写入上限、文件名、读取越界检查 |
| integration | 运行时建目录与可信路径；环境提醒；会话删除后目录被删；第二期的工具存盘和 Bash 存盘 |
| contract | 第二期的两个文件路由 |
| 浏览器走查 | 第二期的 Files 页 |

不测：文件系统本身的行为、`rm` 是否真的删掉了数据。

## 2. Critical Scenarios

### 第一期

| ID | 场景 | 验证点 |
|---|---|---|
| S1 | 路径与校验 | `OHBABY_HOME` 设为临时目录时，路径为 `<home>/sessions/<id>`；含 `/`、`..`、空串、超长的 ID 抛错 |
| S2 | 建目录 | 会话第一次运行后，`sessions/<id>/scratch` 存在，`tool-output/` 还没有；在 POSIX 系统上权限为 0700；从没运行过的会话没有目录 |
| S3 | 免确认读写 | 在默认权限档位下，本会话的写文件、编辑、读文件和 Bash（`echo x > <scratch>/a.txt`）都不弹确认 |
| S4 | 会话隔离 | 根会话 A 读写根会话 B 的存储区时，按外部路径走权限确认 |
| S5 | 子代理共享 | 根会话的两个子代理都用根会话的目录：子代理写进 scratch 的文件，根会话和另一个子代理能免确认读取 |
| S6 | 环境提醒 | 第一轮请求的环境提醒里有 scratch 路径；子代理的提醒里是所属根会话的路径；归属 ID 不合法时提醒里没有这一行，但运行目录、平台、日期都还在 |
| S7 | 上下文重建 | 换运行目录、daemon 重启后，同一会话再次运行仍能免确认读写原来的目录，里面的文件还在 |
| S8 | 删除 | 永久删除一个带子代理的根会话后，它的目录被删除；删除目录失败不影响数据库删除 |
| S9 | 不受影响的操作 | 归档、移动工作区之后目录和文件都还在；撤销重发议题已落地时，撤销后文件也还在；fork 议题已落地时，fork 出来的会话有新目录，里面没有源会话的文件 |
| S10 | 建目录失败 | 让 `sessions/` 不可写：运行照常进行，日志里有错误，写存储区时弹权限确认 |

side chat 的归属（用主会话的目录、关闭时不删除）在 side chat 议题实施时验证，见该议题 04。

### 第二期

| ID | 场景 | 验证点 |
|---|---|---|
| S11 | 工具存盘 | `list`、`glob`、`web` 的输出超过阈值：返回给模型的结果末尾有文件路径，文件里是完整输出；模型能用 `read` 免确认读取；两次调用的 `callId` 相同时写成两个文件 |
| S12 | Bash 存盘 | 输出 1 MB 的命令：结果被截断并附路径，`.log` 文件里有完整输出；超过 10 MB 时文件截在 10 MB 并注明；后台任务结束后文件仍完整 |
| S13 | 存盘失败 | 存盘失败时结果照现在的方式截断，不附路径，不报错 |
| S14 | 列文件 | `GET /files` 只列 `scratch/` 下的文件，不列 `tool-output/` |
| S15 | 读文件越界 | `path` 为 `../x`、绝对路径、指向外部的符号链接时返回 `INVALID_PATH`；超过上限返回 `FILE_TOO_LARGE`；既不是文本也不是图片返回 `UNSUPPORTED_FILE_TYPE` |
| S16 | 鉴权 | 未绑定该会话的客户端访问文件路由被拒绝 |
| S17 | Files 页 | 右侧面板能列出文件，点开文本和图片能预览，其他类型只显示名字和大小 |
