## HTML 安全与资源

- `src/core/export-html/index.ts:159` 将 JSON 做 UTF-8 base64；`template.js:8` 用 atob、Uint8Array、TextDecoder 解码。会话数据中的 script 结束标签不能直接逃出数据容器。
- `template.js:1591` 的 tokenizer.html/tag 返回 undefined，禁用原始 HTML。当前 vendored marked 是 18.0.5；其 override 只有返回 false 才回退旧实现。
- `template.js:619` 删除 C0/DEL 控制字符并检查 scheme；允许 http、https、mailto、tel、ftp 和无 scheme 路径。链接属性与图片属性转义。
- `template.html` 没有 CSP；`template.js:876` 等位置使用内联 onclick。资源内联使基础页面能离线运行，但允许远程 Markdown 图片意味着打开文件仍可能发请求。
- `index.ts:143` 运行时读取 CSS、JS、marked、highlight.js；本次文件大小分别可见 marked 约 43 KB、highlight 约 122 KB、viewer JS 约 80 KB。不是运行时零资源依赖。
- `CHANGELOG.md:2554` 有 binary asset path 修复记录；`:1649` 有 marked 18.0.5 更新记录。

## String.replace 问题的精确范围

`index.ts:169-174` 把 templateJs 直接作为 replacement string。`template.js:1423` 的 Cost 模板包含 `$${totalCost.toFixed(3)}`，replace 会把 `$$` 合成 `$`，从而改变导出后的脚本字符串。

主代理已用最小 Node 实验确认 replacement string 会解释 `$$`，函数 replacement 会原样保留。这里不能说“所有正文美元字符都会丢失”：正文 payload 在该阶段已 base64。

## 推断

“单文件 HTML”和“不会自动联网”是不同保证，依据是内联基础资源与允许远程 Markdown 图片同时存在。Pi 的数据容器与折叠展示可作结构参考，其 systemPrompt、全树与隐藏 custom_message 范围不能视作 ohbaby 的过滤规则。
