# 父子关系作为展示归属依据：模块改造路线

> 2026-09-19 规划，2026-09-21 按讨论修订，尚未实施。属于[执行可靠性四轮路线](../../../problem-lists/2026-09-19-execution-reliability/README.md)。本页说明本模块职责和邻接关系，不是另一份独立实施契约。

## 本轮职责

- 复用 Session.parentId 构建可信根关系；adapter 解析并检测循环、缺父和跨工作区。
- 会话历史关系与 run 身份分开，子代理一生可有多个 run。
- 删除/失效关系需让原请求撤销，不能改挂另一 root。
- 提供不读取消息/run/todo 的主会话元数据查询，支持客户端注册和根选择；先验证关系和范围再提交选择，不因聊天历史失败阻塞有效审批。

## 不承担的职责

- 不存审批 Promise，不承担客户端连接所有权。
- 第一轮不新增独立父子关系表、不重做 conversation 全模块。

## 后续轮次

第三轮提供树状只读浏览所需查询；第四轮维持会话与执行恢复状态一致。
