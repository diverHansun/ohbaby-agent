# ohbaby v0.1.18 — Background Tasks, Side Chats & a Web Terminal

ohbaby v0.1.18 lets long commands continue in the background, gives you more ways to branch or revise a conversation, and brings a terminal and session files into the web UI.

## Highlights

- **Background tasks:** start a command in the background or let a long foreground command move there without restarting it. The agent can inspect, wait for, or stop jobs with the `task` tool. Open **Background tasks** in the web side panel or run `/bg` in the TUI to see status and output and cancel running jobs. Tasks can finish after the current agent turn ends and deliver their results back to the chat.
- **Windows command cleanup:** tracked shell commands use Windows Job Objects to confirm when the job's processes have exited. If cleanup cannot be confirmed, the runtime reports the reason. Once the original backend has exited, you can release tracking without terminating any remaining processes.
- **Side Chat, Fork, and Rewind:** ask a follow-up in a temporary chat, branch a conversation from a finished answer, or go back to a previous prompt and optionally send an edited version. Use the web message actions or `/btw`, `/fork`, and `/rewind` in the TUI. `/btw` in the TUI requires a local session.
- **Terminal and files in the web UI:** open **Terminal** in the side panel for an interactive shell. Use **Files** to browse session artifacts, including saved subagent reports and long tool output. You can also copy messages and code blocks directly from the chat.
- **Model settings and feedback:** model setup can discover reasoning options, and token limit overrides are optional. Web and terminal interfaces show a single waiting state through retries and keep failed turns visible. Subagent results are persisted for recovery and can resume the parent when it is ready.

## Upgrade

Use Node.js 24 or later. Stop the local daemon with `ohbaby serve stop`, then exit all remaining ohbaby processes, including TUIs and SDK hosts, before starting the new version. Upgrade the CLI and any remote clients together, and refresh open browser tabs after upgrading.

```bash
npm install -g ohbaby-cli@0.1.18
ohbaby --version
```

**Database:** the upgrade takes an offline backup of an existing database before applying changes for background task results. Look for `<database-path>.before-retained-<uuid>.backup`. To roll back, stop ohbaby and restore the pre-upgrade backup before starting the older version. Changes made since the backup will be absent. An older version opening the upgraded database can show hidden turns that were rewound and send them to the model again.

**SDK and runtime:** keep `ohbaby-sdk`, `ohbaby-llm`, `ohbaby-agent`, `ohbaby-server`, and `ohbaby-cli` on the same version. Most users only need `ohbaby-cli`.
