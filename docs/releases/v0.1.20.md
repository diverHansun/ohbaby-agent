# ohbaby v0.1.20

The command-line installer now shows which of its four steps is running on Windows, Linux, and macOS. When it downloads Node.js in a terminal, you can watch the download progress. At the end, the installer tells you which version is active, where it put the launcher, and how to start it from your shell.

## Install or upgrade

If you already have v0.1.19, finish any active work and run `ohbaby update 0.1.20`.

**macOS and Linux** (x64 or ARM64, glibc on Linux)

```sh
curl -fsSL https://cdn.jsdelivr.net/npm/ohbaby-cli@0.1.20/install.sh | OHBABY_INSTALL_VERSION=0.1.20 sh
```

**Windows PowerShell** (x64 or ARM64)

```powershell
$env:OHBABY_INSTALL_VERSION = '0.1.20'
try {
    irm https://cdn.jsdelivr.net/npm/ohbaby-cli@0.1.20/install.ps1 | iex
} finally {
    Remove-Item Env:OHBABY_INSTALL_VERSION
}
```

**npm** (all three platforms, requires Node.js 24 or later)

```sh
npm install -g ohbaby-cli@0.1.20
```

Open a new terminal and run `ohbaby --version`. It should print `0.1.20`. On Windows you can also copy the installer’s `Start` command into the current PowerShell session. Run `ohbaby` for the terminal interface or `ohbaby serve` for the Web UI.

## Other changes

- `ohbaby uninstall` reports each step as `done` or `failed`. On Windows it also prints the commands for removing the installation directory.
- In the Web UI, open the model menu to change the reasoning effort. The model button shows the selected level in lowercase.
