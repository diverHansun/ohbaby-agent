# v0.1.13 — Native Reasoning, Responses Protocol & Web Experience

## Highlights

- 新增 OpenAI Responses 协议支持，并将模型请求、流式响应和工具调用迁移到 provider-neutral 契约。
- 新增模型 reasoning 能力探测、会话级推理强度选择和持久化恢复，TUI 与 Web 可根据当前模型能力展示对应选项。
- 改进原生 reasoning、工具调用、多轮历史和中断恢复在 OpenAI-compatible、OpenAI Responses 与 Anthropic 协议之间的一致性。
- 重新校准上下文占用、Prompt Cache 和 token usage 统计，完善自动压缩、失败历史与多步骤生命周期处理。
- 强化模型连接流程，对协议、Base URL、采样参数和 reasoning 配置提供更明确的校验与风险提示。
- 更新 Web 会话界面：重做 header、sidebar、composer、权限确认、用户消息气泡和工具调用行，恢复上下文占用圆环，并改善窄窗口与长输出体验。
- 改进新建会话排序与空会话复用，确保当前会话在创建、刷新和恢复后保持稳定。
- 扩充模型契约、生命周期、缓存统计、TUI、Web 和 compiled browser E2E 覆盖。

## Breaking Changes

本版本包含面向 `ohbaby-agent` 与 `ohbaby-sdk` 编程接口的契约调整。直接集成这些包的调用方需要关注：

- `streamChatCompletion` 更名为 `streamResponse`。
- `ChatCompletionMessage` 与 `ChatFinishReason` 分别替换为 `ModelMessage` 与 `ModelFinishReason`。
- `StreamingResponse.completeMessage` 替换为 `messageSnapshot`。
- reasoning 字段统一为 `reasoningText` 与 `reasoningTextDelta`。
- `ParsedToolCall.id` 替换为 `callId`。
- `StreamingTokenUsage` 不再暴露 `prompt_tokens`、`completion_tokens` 与 `total_tokens` 兼容字段，请使用规范化 token usage 字段。
- `UiCommandClient` 新增 `updateSessionReasoning` 能力。

仅通过全局安装使用 `ohbaby-cli` 的用户无需修改现有命令。
