# ohbaby v0.1.19 — Cross-platform installers and CLI updates

Install ohbaby on macOS, Linux, or Windows with a single command. The new installers set up both the terminal interface and the bundled Web UI, along with a private Node.js runtime.

## Install

**macOS and Linux**

```sh
curl -fsSL https://cdn.jsdelivr.net/npm/ohbaby-cli@0.1.19/install.sh | OHBABY_INSTALL_VERSION=0.1.19 sh
```

**Windows (PowerShell)**

```powershell
$env:OHBABY_INSTALL_VERSION = '0.1.19'
irm https://cdn.jsdelivr.net/npm/ohbaby-cli@0.1.19/install.ps1 | iex
Remove-Item Env:OHBABY_INSTALL_VERSION
```

Open a new terminal after using a script so it picks up the updated PATH. Run `ohbaby --version` to verify the installation, `ohbaby` to open the terminal interface, or `ohbaby serve` to open the Web UI.

The scripts support x64 and ARM64. On Linux, the script requires glibc. On other Linux distributions, use npm with a compatible Node.js installation.

**npm on macOS, Linux, or Windows** · Requires Node.js 24 or later.

```sh
npm install -g ohbaby-cli@0.1.19
```

## Upgrade

**From v0.1.18 or earlier**, let active work finish, exit any open ohbaby terminal sessions, and stop the local daemon with `ohbaby serve stop` if it is running. Then repeat the npm install command above, or use the installer for your platform to switch to a script-managed installation. Both routes keep your configuration and chat history. If you keep both installations, check which `ohbaby` your terminal finds.

**Starting with v0.1.19**, run `ohbaby update` to update the CLI and bundled Web UI through your existing installation method. The updater can stop an idle daemon and blocks the update while it detects active work. Run `ohbaby serve` again when you want to reopen the Web UI.

- Run `ohbaby update --auto on` to opt in to updates at interactive terminal startup. Use `ohbaby update --auto off` to disable them. After an automatic update succeeds, run `ohbaby` again.
- Run `ohbaby uninstall` to remove the program while keeping your user data. After a script install on Windows, follow the final removal instruction printed by the command.
- If you use ohbaby packages as dependencies, update all five packages to `0.1.19` together. Most users only need `ohbaby-cli`.

## Other changes

- **More reliable shutdown.** The local daemon handles stale process locks, tracks cleanup when a shutdown takes longer than expected, and protects active work during update and uninstall checks.
- **Model request retries.** Temporary stream failures can retry the interrupted model step within the retry budget. Both interfaces show retry progress.
- **Web chat history.** Earlier messages load as you scroll up, with conversation history preserved across context compaction. You can also reopen chats from unavailable workspaces and move them to an accessible folder.
- **Subagent models.** Choose a global default model for subagents in Web settings. The Web UI also refreshes subagent runs as their status changes.
- **Model and search settings.** Automatic token limits are more consistent across model routes. Web and terminal search settings now name Tavily and link to its API key page.
