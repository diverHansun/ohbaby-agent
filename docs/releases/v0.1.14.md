# v0.1.14 — TUI Interaction & System Proxy

状态：本地发布准备，尚未发布到 npm 或 GitHub。版本与预定 tag 均为 `v0.1.14`。

## Highlights

- TUI 输出区与输入、任务、审批区域独立布局；修复持续输出时的渲染冲突，支持上滚阅读历史、固定阅读位置和回到底部恢复跟随。
- 改进连续滚轮输入，复用未变化消息的 Markdown 排版；缩小滚动步长并提高交互刷新上限。
- 精简审批与工具输出，减少重复选项和子代理内部状态信息；工具详情、变更摘要与截断提示按需展示。
- 改进中文与字素输入、提示框导航、会话恢复、队列及中断交互，保持终端原有颜色。
- 调整等待动画：星号放慢，光条稍快；保留关闭动画与运行结束后的计时器清理。
- CLI 网络请求跟随系统代理，完善代理状态与配置迁移提示。
- Web 会话侧栏支持置顶与操作菜单，简化工具标题。
- 消除根构建重复构建 workspace 的情况，保留 CLI 独立构建入口。

## Packages

四个公开包统一为 `0.1.14`：`ohbaby-sdk`、`ohbaby-agent`、`ohbaby-server`、`ohbaby-cli`。根 workspace 与私有 Web 包同步版本。公开包内的 workspace 依赖在打包时改写为对应的 `0.1.14`。

继续要求 Node.js >= 24。此处不代表 npm 上已经存在该版本；发布完成后安装命令为：

```bash
npm install -g ohbaby-cli@0.1.14
```

## Notes

- TUI 底部第一行左侧是当前会话的项目目录。新启动尚无活跃会话，或会话未提供 `projectRoot` 时显示 `unknown`；它不表示模型连接或密钥配置异常。
- Web 主 bundle 约 515 kB，仍会出现 Vite 默认 500 kB 的体积提醒；构建成功，本轮没有通过提高阈值隐藏提醒。
- 启动迁移继续保留当前配置并备份旧配置冲突。特定机器确认旧配置迁移已完成后，可使用既有 `.skip-auto-migrate` 标记；该标记不是本版本统一下发的配置。

- macOS arm64、Node 24.20.0、pnpm 9.15.0：`pnpm preflight` 通过，包含格式、lint、类型检查、全量测试及生产构建。516 个测试文件通过、6 个跳过；5701 项通过、17 项跳过。lint 为 0 error、109 条已有 warning。
- 全量测试中的 npm tarball 安装 smoke 通过：使用隔离安装目录验证已打包 CLI 的命令入口与依赖，不借用 workspace 的模块解析路径。
- 四个公开包的 `pnpm pack` 与 `npm publish <tarball> --dry-run --ignore-scripts` 通过；版本及包间依赖均为 `0.1.14`，无残留 `workspace:`，CLI 包包含 Web 静态资源，包内未包含 `.env`、本机运行目录或测试声明文件。

- Web 诊断日志脱敏和五类生命周期事件检查通过；验收服务退出后 PID 与端口均释放。本轮修正旧 E2E 脚本的 stderr 断言，使其接受正常网络策略状态行，仍拒绝 blocked 状态、额外输出及缺失状态；没有隐藏产品警告。
