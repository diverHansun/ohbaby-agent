# 验收标准 · 从 Web 选档到网关收包

当前为实施前方案。前期直连网关的对照见 [03](03-reference-projects.md)；下列真实验收须在实现完成后由 ohbaby 发起。

## 自动化回归

| 接缝 | 用例与断言 |
| --- | --- |
| 目录解析 | 无 Magpie 字样的域名、provider、模型名。分别只给字符串数组、只给对象数组、两者相同或冲突（含首字段只有 minimal、次字段 high 的 Anthropic 场景）、第一种为空或无可用档、大小写扩展名。断言单字段可用、首个可用字段优先、扩展名称和顺序保留、重复或畸形项跳过。用一个虚构的扩展值防止把 ultra 特判写进代码。 |
| 能力优先级 | 完整对象与简写同时存在、两个完整键中首个非法、二者均非法配 false、`reasoning:false`、只有 true、仅空数组或 off 哨兵、["OFF","high"]。断言完整能力优先、false 与 unknown 可区分、简写不宣称 Off。含 minimal 和 ultra 的目录分别经过三个协议，检查 Anthropic 已有 minimal 迁移与显式映射，验证 ultra 已声明且可选。 |
| 发现服务 | 保存及 Detect again。有目录证据时只读取目录（允许分页），生成 POST 为零，写入来源 model-metadata。缺字段沿用原主动探针；严格拒绝非法值的服务能枚举档位，宽容端点在无旧证据时保持 unknown。有同路由旧证据时重测失败按既有逻辑保留。增加同路由先前已确认 Off 且用户显式关闭的夹具，简写刷新后 Off 偏好保留；换路由不会继承该证据。复用现有过期结果、鉴权和限流回归。 |
| 发送器与会话 | 将已知标准值和目录声明的任意扩展字符串经配置解析、会话选择与三个发送器送到记录请求的本地端点。断言 wire 上与所选字符串完全一致，未声明的选择按现有校验处理。补一个服务端确实拒绝档位的负例，错误可见且不会自动改发较低档。保留 Responses include、工具字段、Anthropic adaptive 与已有完整能力的语义。 |

扩展现有 reasoning-discovery、model-entry-probe 和 provider 测试；目前已覆盖的分页、超时等用例直接复跑。按仓库测试指南串行运行会争用 CLI 构建的检查，记录实际命令与退出码。

## 本机真实请求与 Web 端到端

| 行 | 模型 | 入口 | Web 明确选档 | 目的 |
| --- | --- | --- | --- | --- |
| A–C | auto/gpt-6.1-sol | Chat、Responses、Anthropic 各一次 | ultra | 同一模型、同一扩展值，分别核对三种实际请求体 |
| D | auto/gemini-4-carbon | Chat | high | 复现用户最初的 Not detected，再验证已能选择三档 |
| E | auto/gemini-4-neon | Responses | xhigh | 同家族模型不同档位集，验证四档 |
| F | auto/deepseek-v4.1-flash | Anthropic | max | 检验离散的 low/high/max，菜单没有凭空补出 medium |

1. 使用独立的 ohbaby 配置、数据库、工作区和端口，访问本机 Magpie。记录当日版本、完整模型 ID、入口和实际目录。用内置浏览器在 Settings 按行创建或重测条目，比较设置读取、会话菜单和目录。通过来源/网络记录核对发现行为。A–C 通过 Settings 的新增模型入口分别建可区分的条目，以免把同名模型的另一协议选作证据。
2. 每行用 Web 新建会话，选表中档位并发题，验证可核对的最终回答。经现有请求观察点或临时的本机透明转发，记录 agent-step 的 HTTP path、model、精确 effort 字段、stream 和工具声明。排除标题请求与探针。每个协议至少一行在临时目录读取随机值，走完工具调用、工具结果及带同档位的后续请求。可以把实机请求和 Web 验收合为一次发送。
3. **分开记录三种值**：Web 所选、ohbaby 发往 Magpie 的值、Magpie 或上游回报的值。A–C 前两者必须都是 ultra；第三项允许按事实记为 max、其他值或未提供。若客户端先改成 max，判失败；若客户端确实发出 ultra 且网关回报 max，记录服务端归一化。这样才能发现本次 HTTP 请求还未发出就被拦截的回归。
4. 刷新页面、重进会话，核对选择；至少一次重启隔离服务后复核目录结果仍可读取。同名模型三入口的配置不相互污染。留脱敏请求摘要、结果、截图和版本，清理测试会话环境。模型临时下线时可选具同等特征的替代，但原失败和替代条件必须可辨认；若没有可声明扩展档的真实路由，此项保持待验收。
5. Thinking 只旁观。若发现必须调整展示才可解决的独立问题，提交原始事件类型和界面现象给用户决定。实施后的 05 分列自动化、三入口实测和 Web 结果。
